# 腐败网络调查启发式规则库

本文件记录从多次调查中萃取出的可复用结构签名（structural signatures）与调查模式。每次完成重大案件调查后，应通过 `investigation_retrospector.py` 审阅并更新本库。

---

## 签名 S1：双层职务掩护

- **结构模式**：`protector` 类型节点同时具有两条 `affiliated_with` 边，分别指向 `institution`（医院主体）和 `institution`（具体科室）
- **典型节点**：科室主任 / 病区主任
- **含义**：该节点同时拥有行政合法性（医院主体）和实际资源分配权（科室）。当该节点再通过 `shelter` 边指向 `core_subject` 时，构成完整的结构性庇护链。
- **置信度升级**：
  - 仅有双层 `affiliated_with` → L2（线索）
  - 同时存在 `shelter` 边 → L4（高度可能）
- **首次发现案例**：湘雅系（某主任J→湘雅二院+普外科二病区；某主任K→湘雅二院+肾脏移植科）
- **常见误报**：大型三甲医院的科室主任天然具有双层隶属关系（医院+科室），单独出现不应升级。需同时存在 `shelter` 边才有意义。

## 签名 S2：学术真空期后的突兀包装

- **结构模式**：`core_subject` 在 ≥5 年内无第一作者或独立署名论文，随后突然出现一篇由 `academic`/`protector` 节点共同署名的论文，且该论文涉及高难度手术病例
- **典型边类型**：`academic_packaging`
- **含义**：存在将科室集体积累的病例资源/技术成果挂名为个人学术产出的迹象。中间往往需要一个“桥梁节点”（bridge node）跨越真空期。
- **置信度升级**：
  - 仅有真空期 + 突兀论文 → L3（疑似）
  - 同时有 `protector` 提供通信作者 / 手术签名背书 → L4（高度可能）
- **首次发现案例**：湘雅系（CASE_002 2006-2014 年学术真空期，2014 年《绕肝提拉法》论文由某医生H、某医生I共同署名）
- **常见误报**：学者转换研究方向、产假/病假后复出、从临床转科研等情况也会出现真空期。需结合职业履历判断真空期是否合理。

## 签名 S3：死亡事件后的通讯异常与官方回避

- **结构模式**：网络中存在 `death_event` 案件节点，死者生前收到第三人称口吻的通讯记录（短信、语音、社交媒体消息），而官方通报对这类异常通讯完全回避或给出不合理解释
- **负面空间指标**：`negative_space.matrix` 中相关问题的 `score` 为 0.0，`evasion_score` 通常 > 0.6
- **含义**：死亡事件的官方定性（如“自杀”）与现有物证存在显著矛盾，通报文本倾向于选择性沉默而非正面解释。
- **置信度升级**：
  - 仅有第三人称通讯记录 → L3（疑似）
  - 官方通报完全未回应 + 存在其他物证（如备用手机报警录音） → L4（高度可能）
- **首次发现案例**：湘雅系（某实习生坠亡前收到”去_RSP_会议室”第三人称短信，通报未提及；另有一部手机报警记录未解释）
- **常见误报**：第三人称口吻短信可能来自秘书代发、系统自动通知等正常场景。需结合死亡事件的时间线和官方回避程度综合判断。

## 签名 S4：跨机构无资质科研合作

- **结构模式**：`project_collab` 边连接的医院/科室（`institution` 或 `academic` 节点）与外部机构之间，外部机构缺乏开展该研究所需的法定资质（如器官移植资质、伦理审查资质）
- **典型边类型**：`project_collab`
- **含义**：科研项目可能绕过正规伦理审批与资质监管，存在非法收集人体标本或数据的重大嫌疑。
- **置信度升级**：
  - 外部机构无资质但参与合作 → L4（高度可能）
  - 同时存在 `money_laundering` 或绩效中转迹象 → 接近 L5（需独立来源确认）
- **首次发现案例**：湘雅系（襄阳健桥医院无器官移植资质，却与湘雅二院肾脏移植科合作”3-9岁儿童标本收集项目”）
- **常见误报**：跨机构合作本身是正常学术行为。需确认合作内容确实需要特定资质（如器官移植、人体试验），且合作方确实缺乏该资质。

## 签名 S5：绩效/资金洗钱链（研究生账户中转）

- **结构模式**：`core_subject` 或普通节点（如研究生、实习生）账户收到大额科室绩效/资金，随后迅速转回 `accomplice` 或 `protector` 关联的账户（如原护士长、科研秘书）
- **典型边类型**：`money_laundering`
- **含义**：利用学生/初级员工账户作为资金中转站，规避财务审计与税务监管，形成系统性洗钱通道。
- **置信度升级**：
  - 仅有一次大额资金往来 → L3（疑似）
  - 存在周期性、多笔中转，且收款人为科室管理人员 → L4（高度可能）
- **首次发现案例**：湘雅系（某实习生账户收到科室绩效 33.379 万元，其中 29.526 万元转回某护士长——肾脏移植科原护士长账户）
- **常见误报**：部分医院的绩效发放确实通过个人账户中转（如代领奖金），需确认转账金额与频率是否显著偏离正常绩效水平，且收款方是否为管理层。

## 签名 S6：论文工厂模式（批量挂名与幽灵作者）

> ⚠️ **来源标注**：理论推导 + 文献来源（基于 Retraction Watch 论文工厂数据库特征总结），尚无本系统直接调查的实案支撑。

- **结构模式**：`core_subject` 或 `academic` 节点在 1-2 年内以第一作者或通讯作者身份突然发表 ≥5 篇论文，且这些论文的 `collaborates_with` 边指向大量从未在其他论文中出现过的合作者（幽灵作者），或合作者之间存在高度重叠的作者组合
- **典型边类型**：`academic_packaging`、`academic`
- **含义**：存在论文工厂代写、批量挂名或模板化产出的迹象。幽灵作者可能是真实存在的基层研究人员（被买通挂名），也可能是完全虚构的身份。
- **辅助指标**：
  - 多篇论文标题结构高度相似（如仅替换地名/变量名）
  - 论文发表于掠夺性期刊或已知论文工厂目标期刊
  - 同一批次论文的投稿时间间隔极短（<30 天）
- **置信度升级**：
  - 仅有批量高产 + 幽灵作者 → L3（疑似）
  - 同时存在模板化标题 + 掠夺性期刊 → L4（高度可能）
  - 有内部举报人证词或通讯记录显示代写交易 → L5（需独立来源确认）
- **首次发现案例**：理论推导（基于 Retraction Watch 论文工厂数据库特征）
- **常见误报**：高产学者（如大团队 PI）在短期内发表多篇论文属于正常现象。需确认合作者是否真实存在且有对应研究能力，而非仅看数量。博士毕业前集中发表也是常见正常模式。

## 签名 S7：评审自循环（审稿利益闭环）

> ⚠️ **来源标注**：理论推导 + 文献来源（基于学术出版伦理研究及 COPE 案例库），尚无本系统直接调查的实案支撑。

- **结构模式**：`core_subject` 同时担任某期刊编委（`editorial_board` 边），且该期刊在 `core_subject` 任编委期间发表了其学生（`academic` 节点）或合作者（`collaborator` 节点）的 ≥3 篇论文，而 `core_subject` 本人也在同期于该期刊发表了 ≥2 篇论文
- **典型边类型**：`editorial_board`、`academic`
- **含义**：利用编委身份影响审稿流程，形成"自己审自己人"的利益闭环。可能表现为快速审稿、降低标准、回避关键质疑。
- **辅助指标**：
  - 审稿周期异常短（<14 天从投稿到接收）
  - 审稿意见明显偏袒，回避方法学缺陷
  - 同一批次稿件中，编委关联作者录用率显著高于非关联作者
- **置信度升级**：
  - 仅有编委身份 + 同期多发论文 → L2（线索）
  - 同时审稿周期异常短 + 审稿意见偏袒 → L4（高度可能）
  - 有内部邮件或审稿系统日志显示干预行为 → L5（需独立来源确认）
- **首次发现案例**：理论推导（基于 COPE 案例库及学术出版伦理研究）
- **常见误报**：编委在自己期刊发表论文本身是允许的（多数期刊有回避制度）。需确认审稿周期是否异常短、是否存在系统性偏袒模式，而非个别论文。

## 签名 S8：奖项买卖链（真假奖项混排）

> ⚠️ **来源标注**：理论推导 + 文献来源（基于 Beall's List 掠夺性会议/奖项研究及学术履历审计经验），尚无本系统直接调查的实案支撑。

- **结构模式**：`core_subject` 的履历中列出的奖项包含 ≥2 个已知付费奖项（如某些国际会议"最佳论文奖"、商业机构颁发的"杰出学者奖"），且这些奖项与真实学术奖项（如国家级社科奖、教育部奖项）在履历中混合排列，不做区分
- **典型边类型**：无特定边类型，属于 `basic_profile` 中的 `awards` 字段异常
- **含义**：通过购买或伪造低质量奖项来填充学术履历，制造"获奖众多"的假象。付费奖项通常没有公开的评审标准、评审委员会名单或往届获奖者名单。
- **辅助指标**：
  - 奖项颁发机构无官方网站或网站内容粗糙
  - 奖项评审标准模糊（如"基于学术影响力"但无具体指标）
  - 同一年度该奖项有异常多的获奖者（>50 人）
  - 往届获奖者中出现已知的学术造假者或掠夺性期刊编辑
- **置信度升级**：
  - 仅有付费奖项 + 混合排列 → L3（疑似）
  - 同时奖项机构无官网或往届名单含造假者 → L4（高度可能）
- **首次发现案例**：理论推导（基于 Beall's List 掠夺性会议/奖项研究及学术履历审计经验）
- **常见误报**：部分正规国际学术会议也会颁发"最佳论文奖"，需核实颁发机构是否在 Beall's List 或已知掠夺性名单中。行业协会颁发的荣誉奖也可能被误判。

## 签名 S9：学位论文自我抄袭或跨校抄袭

> ⚠️ **来源标注**：理论推导 + 文献来源（基于学术不端检测系统如 iThenticate/CNKI 查重的常见模式），尚无本系统直接调查的实案支撑。

- **结构模式**：`core_subject` 的博士学位论文（或早期硕士论文）与其后期发表的期刊论文之间存在 ≥15% 的文本重复率（排除方法论和文献综述部分），或论文中的核心数据/图表在未经许可的情况下出现在其他院校的学位论文中
- **典型边类型**：`academic`
- **含义**：将学位论文内容拆分发表（自我抄袭），或直接从其他学者/学生的学位论文中复制核心内容（跨校抄袭）。自我抄袭虽然不涉及学术不端的主观恶意，但违反了一稿多投原则；跨校抄袭则是严重的学术不端。
- **辅助指标**：
  - 学位论文的发表时间早于期刊论文，但期刊论文未标注"部分内容来自学位论文"
  - 核心数据在不同论文中出现，但数据来源声明不一致
  - 跨校抄袭案例中，被抄袭论文的作者与抄袭者无合作关系
- **置信度升级**：
  - 仅有文本重复率 15-25% → L2（线索，可能属于合理引用）
  - 重复率 >25% 且涉及核心论点/数据 → L3（疑似）
  - 同时存在跨校抄袭 + 数据来源声明不一致 → L4（高度可能）
- **首次发现案例**：理论推导（基于 iThenticate/CNKI 查重系统常见模式）
- **常见误报**：学位论文拆分发表在部分学科（如工科）是被允许甚至鼓励的做法，需确认所在学科的惯例。方法论部分的重复通常不构成自我抄袭。

## 签名 S10：虚假海外背景包装

> ⚠️ **来源标注**：理论推导 + 文献来源（基于教育部学历认证系统及海外访学制度研究），尚无本系统直接调查的实案支撑。

- **结构模式**：`core_subject` 的履历中声称具有海外学位（如"美国 XX 大学博士"）或海外教职经历（如"曾任哈佛大学访问学者"），但经核实：海外学位无法在官方数据库查询到，或访问学者经历实际为短期旅游签证（<3 个月）而非正式学术访问
- **典型边类型**：`education`（时间轴事件中的教育背景）
- **含义**：将短期旁听、自费访学、甚至旅游经历包装成正式的海外学术背景，以提升学术声誉和职称评审竞争力。常见于缺乏真实海外经历的学者。
- **辅助指标**：
  - 声称的海外学位授予年份与 `career_timeline` 中的国内任职时间重叠
  - 海外机构官网无该学者的学生/访问学者记录
  - 声称的导师姓名在海外机构官网无对应人员
  - 护照/签证记录显示访问时间极短（<30 天）或签证类型为旅游签（B1/B2）
- **置信度升级**：
  - 仅有学位无法查询到 → L3（疑似）
  - 同时时间线重叠 + 签证类型不符 → L4（高度可能）
  - 有内部通讯录或同学证词确认从未见过此人 → L5（需独立来源确认）
- **首次发现案例**：理论推导（基于教育部学历认证系统及海外访学制度研究）
- **常见误报**：部分联合培养项目（如 CSC 公派）确实时间较短（3-12个月），但属于正式学术访问。需区分"正式公派访学"与"自费旅游式访学"，核实是否有接收函和正式合作协议。

## 通用调查流程建议

### 医疗系统腐败网络必查项
1. **查双层职务掩护**：核心科室主任是否同时挂靠医院主体和具体科室？
2. **查手术签名链**：`core_subject` 的手术记录中，主刀/一作署名是否为 `protector` 节点？
3. **查论文真空期**：是否存在长期无产出后突然发表高难度手术论文？
4. **查跨机构合作**：合作方是否具备相应医疗/伦理资质？
5. **查资金中转**：研究生/进修医生账户是否出现大额科室资金往来？
6. **查负面空间**：官方通报中是否回避了”独立第三方复核””异常通讯记录””具体问责名单”等关键问题？

### 学术诚信调查必查项
7. **查论文工厂**：短期（1-2年）内是否出现大量论文且合作者高度重叠或从未出现过？
8. **查评审自循环**：是否担任期刊编委期间大量发表自己人论文？审稿周期是否异常短？
9. **查奖项真假**：履历中的奖项是否有已知付费奖项混入？颁发机构是否可查？
10. **查学位论文抄袭**：学位论文与后期期刊论文的文本重复率是否异常？是否存在跨校抄袭？
11. **查海外背景真伪**：声称的海外学位/教职是否能在官方系统查询到？时间线是否重叠？
12. **查数据一致性**：不同来源（知网、万方、WoS）的论文数量是否一致？是否有”声称”与”核实”的显著差异？

### 论文级数据造假必查项（PDF 审查 / 耿同学六式）
13. **查图片复用**：同一论文的不同 Figure 面板是否重复？Western blot loading control 是否在不同条件下完全相同？
14. **查数据编造**：表格数据末位数字分布是否异常？标准差是否过于整齐？两组”独立实验”数据是否完全相同？
15. **查图片拼接**：Western blot 泳道间是否有不自然分界线？背景灰度/纹理是否一致？
16. **查统计异常**：p 值是否大量聚集在 0.04-0.05？F 值/t 值与自由度是否匹配？
17. **查方法矛盾**：Methods 中的 n 值是否与表格一致？试剂/设备型号是否存在？伦理审批号是否有效？
18. **查时间线冲突**：实验周期 vs 投稿时间是否合理？是否使用了投稿时尚未上市的试剂？
