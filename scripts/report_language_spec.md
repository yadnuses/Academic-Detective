# 学术调查报告语言规范（Language Specification）

> **用途**：本规范供 `report_prompt_optimizer.py` 在生成 LLM prompt 时自动注入，确保所有定性判断的措辞与证据强度严格匹配，规避法律风险。
>
> **核心原则**：宁可弱化表述，也绝不一锤定音。没有多重独立证据支撑的负面判断，只能停留在"线索"或"迹象"层面。

---

## 一、置信度五级体系

每一条定性判断都必须落在以下五个等级之一。**严禁越级表述**——证据只够"疑似"时，绝不能用"可确认"。

| 等级 | 代码 | 定义 | 证据要求 | 典型措辞 |
|:---:|:---:|:---|:---|:---|
| **确认** | `L5` | 事实清楚，无争议 | ≥2 个独立来源交叉验证，且均为官方/权威来源 | "经查证""可确认""记录显示" |
| **高度可能** | `L4` | 证据较强，少量合理推断 | 强证据（如官方数据库）+ 1 个辅助来源，或逻辑上难以反驳的间接证据链 | "极有可能""高度疑似""强烈暗示" |
| **可能/疑似** | `L3` | 有证据，但存在其他解释空间 | 单一可靠来源，或多条弱证据指向同一方向 | "疑似""存在…迹象""有…嫌疑""可能涉及" |
| **线索/传闻** | `L2` | 仅有微弱信号或匿名信息 | 匿名评价、社交媒体传言、单一非权威来源 | "有…传言""评价中提及…""部分受访者反映""一种说法是" |
| **无证据** | `L1` | 没有任何可验证的信息 | — | 不表述该维度，或明确说"未找到相关证据""现有公开信息不足以判断" |

### 使用规则

1. **降级原则**：当证据处于两个等级之间时，**向下取整**。宁可保守，不可冒进。
2. **复合判断拆分**：一个涉及多因素的复杂判断，必须拆分为多个子判断，每个子判断独立标注置信度。
3. **时间衰减**：3 年以上的旧证据，在涉及"当前状态"判断时自动降级一级（L5→L4，L4→L3，以此类推）。

## 二、定性表述措辞模板

### 2.1 负面发现（红旗/黄色信号）

根据置信度选择措辞：

| 发现类型 | L5（确认） | L4（高度可能） | L3（疑似） | L2（线索） |
|:---|:---|:---|:---|:---|
| 数量夸大 | "经查证，其声称的 X 篇论文中，Y 篇无法核实" | "极有可能存在数量夸大，核实数与声称数差距显著" | "疑似存在数量注水迹象，建议进一步核实" | "有传言称其成果数量与实际情况不符" |
| 质量低下 | "可确认，其近 3 年核心期刊论文占比为 X%，低于学科正常水平" | "高度疑似存在发表渠道下沉问题" | "存在发表渠道质量偏低的迹象" | "部分评价提及论文质量参差不齐" |
| 学术不端 | — | — | "存在一稿多投/数据异常的嫌疑（具体见第 X 节）" | "有匿名评价反映存在学术不规范行为，尚未获得可验证证据" |
| 师生关系 | "记录显示，其名下学生平均毕业年限为 X 年，超出标准学制 Y 年" | "极有可能存在延期毕业率偏高的问题" | "存在延期毕业率偏高的迹象" | "多条匿名评价反映毕业难度较大" |
| 抢一作 | "经查证，近 3 年其作为第一作者的论文占团队总产出的 X%" | "高度疑似存在导师署名不当问题" | "存在导师署名权分配异常的迹象" | "有学生评价反映导师占据第一作者位置" |
| 压榨学生 | — | — | "存在压榨学生劳动力的嫌疑" | "部分匿名评价使用了'压榨''剥削'等负面词汇" |

**关键红线**：
- **绝对禁止使用** "学术造假""学术腐败""学术骗子""学阀""水货"等定性标签，除非有司法/学校官方处罚决定书作为证据（即便如此，措辞也应为"曾被认定为学术不端"而非"是学术骗子"）。
- **绝对禁止使用** "典型的…案例""属于…""结论为…""毫无疑问"等一锤定音表述。

### 2.2 正面发现（应予肯定的方面）

正面评价同样需要证据支撑，但可以适当放宽标准（因为正面评价不带来法律风险）。

| 置信度 | 措辞 |
|:---|:---|
| L5 | "经查证，其在 X 领域发表了 Y 篇 CSSCI 论文，形成了稳定的研究方向" |
| L4 | "从现有记录看，其在 X 方向有持续的学术投入" |
| L3 | "部分成果显示出对 X 问题的关注" |

### 2.3 中性/描述性表述

纯描述性事实（如"发表论文 X 篇""现任 Y 教授"）不需要置信度前缀，但必须标注数据来源。

## 三、禁用词清单（Prohibited Phrases）

以下词汇和句式在任何置信度级别下都**禁止使用**。如 LLM 生成中包含这些词汇，必须在后处理阶段替换或删除。

### 3.1 绝对化定性标签

| 禁用词 | 替换为 |
|:---|:---|
| "学术造假" | "存在数据/图片异常迹象" / "有学术不规范嫌疑" |
| "学术腐败" | "存在利益冲突迹象" / "资源分配模式值得关注" |
| "学术骗子" | "其部分学术声明与公开记录存在差异" |
| "学阀" | "在特定机构/领域内具有较高的学术影响力" |
| "水货" / "水论文" | "发表渠道质量偏低" / "期刊影响力有限" |
| "学术垃圾" | "学术贡献有限" / "创新性不足" |
| "典型的…" | "呈现出…特征" / "存在…模式" |
| "毫无疑问" | "从现有证据看" / "基于当前可核实信息" |
| "结论是…" | "分析表明…" / "现有信息指向…" |
| "属于…（负面类型）" | "具有…（中性描述）特征" |

### 3.2 情绪化形容词

| 禁用词 | 替换为 |
|:---|:---|
| "无耻""卑鄙""阴险" | 删除，改用客观描述 |
| "黑心""恶毒""人渣" | 删除，改用客观描述 |
| "严重"（用于主观判断时） | 视语境改为"显著""值得注意"或删除 |
| "极度""非常""极其" | 删除或改为量化表述 |

### 3.3 因果断言句式

| 禁用句式 | 替换为 |
|:---|:---|
| "这说明…" | "这可能暗示…" / "一种解释是…" |
| "证明了…" | "支持了…的可能性" / "与…一致" |
| "导致…" | "与…存在关联" / "可能是…的影响因素之一" |
| "因为…所以…"（推断性因果） | "…与…在时间上相继出现，但因果关系尚待进一步验证" |

## 四、正面对比示例（Good vs Bad）

以下示例供 LLM 在生成报告时参考。**Bad 示例中的表述必须避免，Good 示例中的表述优先采用。**

### 示例 1：论文数量差异

- **Bad**："该学者虚报论文数量，是典型的学术不端行为。"
- **Good**："经查证（CNKI，2026-04-14，作者='张三' AND 单位='东方理工大学'，39 条结果），其声称的'70 余篇'论文中，约 44% 无法在权威数据库中核实。建议进一步核查未匹配论文的发表渠道与体例。"

### 示例 2：研究方向集中度

- **Bad**："该学者研究过于单一，缺乏学术视野，只会炒冷饭。"
- **Good（聚焦型，正常）**："其近 10 年研究主要集中于'宏观经济周期'领域（约占总产出的 78%），在'滤波方法'和'金融周期'两个子方向上形成了持续积累。这种聚焦度在人文学科属于常见模式，符合'专精'而非'狭隘'的界定标准（参见基准线文档§3.1）。"
- **Good（跨度型，正常）**："其研究横跨'宏观经济''金融监管''经济思想史'三个领域。跨度虽大于单一方向学者，但三个主题之间存在明确的方法论和理论关联（均围绕'金融与实体经济的互动'这一核心问题）。未观察到'频繁跳题、无累积性'的异常模式（参见基准线文档§3.1）。"

### 示例 3：学生延期毕业

- **Bad**："该导师恶意卡学生毕业，造成了多名学生延毕。"
- **Good**："CNKI 学位论文库显示，其名下 2018-2023 年入学的博士生中，已知毕业年份的 5 人平均就读年限为 5.8 年（该校该专业标准学制为 4 年）。其中 3 人超出标准学制 1 年以上。延期毕业的可能原因包括研究进度、论文质量、个人规划等多种因素，目前尚无法将延期单一归因于导师指导方式（置信度：L3，疑似）。"

### 示例 4：导师一作问题

- **Bad**："该导师抢学生一作，剥削学生成果。"
- **Good**："在其团队 2020-2025 年发表的 23 篇论文中，导师作为第一作者（含共同一作）的论文有 11 篇（47.8%）。在理工科领域，资深导师作为通讯作者更为常见，routine 性占据第一作者位置值得关注（置信度：L3，存在署名权分配异常迹象）。需结合具体学科惯例和作者贡献声明进一步判断。"

### 示例 5：学术质量总体评价

- **Bad**："该学者的论文质量很差，没有任何学术价值。"
- **Good**："对其 12 篇核心论文的六维评分结果显示：平均 68.3 分（B 级），最高 82 分（B+），最低 51 分（C）。评分分布显示其产出质量存在较大方差，部分论文在'技术严谨性'和'数据质量'维度得分偏低。整体而言，其学术产出处于'专业期刊可接受但缺乏顶级期刊冲击力'的水平（参见基准线文档§2.2）。"

## 五、学科差异调整规则

### 5.1 人文社科（HSS）vs 理工科（STEM）

| 维度 | HSS 正常基准 | STEM 正常基准 | 跨学科误评风险 |
|:---|:---|:---|:---|
| 年均论文数 | 0.5-2 篇 | 2-5 篇 | 用 STEM 标准评价 HSS 学者会得出"产出低下"的误判 |
| 期刊类型 | CSSCI、北大核心、SSCI | SCI、EI、顶会 | 用 SCI 标准评价纯 HSS 学者无意义 |
| 导师一作 | 导师作为合作者正常，但学生学位论文章节应学生一作 | 导师通常通讯作者，routine 一作异常 | 混用标准会导致矛盾判断 |
| 研究聚焦度 | 1-2 个主题为正常，深度优先 | 1-3 个相关方向为正常 | 对 HSS 学者说"研究单一"是误判；对 STEM 学者说"跨度大"需看方向关联性 |
| 专著权重 | 专著是核心产出，权重高于期刊论文 | 专著权重低，期刊论文为主 | 忽视专著会低估 HSS 学者贡献 |

### 5.2 职称/ career stage 调整

| 指标 | 副教授正常区间 | 教授正常区间 | 资深教授/院士正常区间 |
|:---|:---|:---|:---|
| 年均论文数 | 1-3 篇 | 2-4 篇 | 1-3 篇（可能下降） |
| 一作比例 | 较高（建立学术声誉期） | 中等 | 低（多为通讯/最后作者） |
| 新方向开拓 | 偶尔尝试 | 可以主导新方向 | 可以设立全新领域 |
| 学生数量 | 3-6 人在读 | 5-10 人在读 | 8-15 人在读 |

## 六、自动化检查清单

在报告生成后，执行以下自动化检查：

- [ ] 报告中是否出现禁用词清单中的任何词汇？
- [ ] 每一条负面判断是否标注了数据来源？
- [ ] 每一条负面判断的措辞是否与证据强度匹配（无越级）？
- [ ] 是否包含至少一条正面评价？
- [ ] 免责声明是否完整保留？
- [ ] 所有"疑似"级及以上的判断是否有≥1个独立来源？
- [ ] 是否对不同 career stage / 学科的学者使用了匹配的基准线？
