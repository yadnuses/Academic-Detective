# 学术调查工作手册（详细步骤版）

> 基于 `academic-investigation-skill` 的 7 步框架与半自动工具链编制。
> 本手册为调查执行者提供可落地的操作流程、命令示例与检查清单。

---

## 工作理念：半自动调查（Human-in-the-Loop）

脚本负责重复性计算与文本解析，**人类判断**始终居于核心位置：
- **人做**：数据库检索、来源交叉验证、最终结论定性、伦理把关。
- **脚本做**：PDF 文本提取、结构化数据统计、报告 prompt 组装、数据一致性校验。

## Step 1：基本信息与教育背景采集

**目标**：建立学者的身份基线与时间轴，确保每一个日期、职称、学位都有可追溯来源。

### 1.1 信息收集清单

| 类别 | 来源 | 关键检查 |
|:---|:---|:---|
| 姓名/现任机构/职称 | 机构官网师资页、院系导师页 | 与百度百科、知网学者库交叉比对 |
| 教育背景 | 学位论文数据库、毕业院校档案馆 | 确认毕业年份、导师姓名、学科方向 |
| 职业时间轴 | 机构官网历史页面、聘任公示、互联网档案馆 | 标注每一次职称晋升与岗位变动 |
| 现任行政职务 | 院系领导名单、聘任工作小组公示 | 注意"专业负责人""系主任"等头衔 |
| 海外经历 | 官网简介、学位论文致谢、维基百科 | 区分"访问学者""博士后""研究员"，警惕表述升级 |

### 1.2 常用检索路径

- **机构官网**：`https://[学校域名]/[院系]/info/xxxx/xxxx.htm`
- **知网学位论文**：CNKI 博硕士论文库，检索"导师=学者博士导师"+
- **互联网档案馆**：`web.archive.org`，追溯历史版本的机构简介和学者主页
- **百度百科/搜狗百科**：仅作交叉参考，不可作为独立证据

### 1.3 微信公众号补充搜索（小道消息与机构动态）

作为学术数据库不会收录的信息补充渠道：

```bash
# 搜索学者相关的公众号文章（著作宣传、机构新闻、传言等）
python3 /Users/xiaoy/Downloads/academic-investigation-skill/scripts/investigate.py wechat \
  --keyword "学者姓名" --limit 10 --output ./data/wechat_articles
```

**注意**：微信公众号信息可靠性为 ⭐☆☆☆☆，只能作为假设生成器。任何发现必须在后续步骤中通过官方渠道交叉验证。引用时统一标注为"微信公众号"，不得暴露技术实现细节。

### 1.4 检查点

- [ ] `config.yaml` 已完整填写学者身份与待验证声明
- [ ] 已保存机构官网师资页原始 HTML 或整页截图（含 URL 和时间戳）
- [ ] 已建立学位-任职-晋升的时间轴表格
- [ ] 所有关键日期均有 ≥2 个独立来源佐证
- [ ] 负面搜索（查不到的信息）已记录数据库名称、检索词、日期

## Step 2：学术产出数量核实

**目标**：对比"声称"与"核实"的论文、专著、项目数量，标记夸大与注水。

### 2.1 人工数据库检索（必须由人完成）

**检索策略**：以 `"学者姓名" + "机构名称"` 为基准查询式，在以下数据库分别检索：

| 数据库 | 检索字段 | 输出动作 |
|:---|:---|:---|
| **中国知网（CNKI）** | 作者 + 单位 | 导出检索结果（JSON/Refworks），记录查询字符串与结果数 |
| **万方数据** | 作者 + 单位 | 同上，用于交叉验证 |
| **Web of Science** | Author + Address | 适用于有英文产出的学者 |
| **维普** | 作者 + 机构 | 补充被引量与期刊来源信息 |
| **Google Scholar** | 学者个人主页 | 核对 h-index 与代表作，但须与 CNKI 核实数并列呈现 |

**记录格式示例**：
> "CNKI, 2026-04-14, author='张三' AND institution='东方理工大学', 39 results"

### 2.2 核实维度（5 维产出评估）

对检索结果逐条快速过筛，评估以下维度：

| 维度 | 检查要点 | 红旗信号 |
|:---|:---|:---|
| 研究方向 | 是否有持续聚焦的主题？论文之间是否存在累积性？ | 频繁跳题、无逻辑递进 |
| 产出数量与频率 | 近 3-5 年是否年均至少 1 篇同行评审论文？ | **连续两年零产出** |
| 期刊质量 | 人文社科看 CSSCI/北大核心；理工科看 SCI/SSCI 分区 | 大量付费开源低质期刊（普刊） |
| 作者排序 | 人文社科：学位论文章节须学生一作；理工科：导师 routinely 占一作是大问题 | 学生多年无一作论文 |
| 内容区分度 | 近期论文是否提出真正的新论点、新数据、新方法？ | "换汤不换药"，同一框架 superficial 改头换面多发 |

### 2.3 构建 CLAIMED vs. VERIFIED 对照表

在 `config.yaml` 的 `claims` 区块填写学者自我声称的数字，在调查笔记中建立核实表：

| 项目 | 声称 | 核实数 | 核实来源 | 差异 |
|:---|:---|:---:|:---|:---:|
| 论文总数 | 70余篇 | 39篇 | CNKI 2026-04-14 | -44% |
| CSSCI | 30余篇 | 6篇 | CNKI + 万方交叉 | -80% |
| 专著 | 4部 | 2部独著+1部合著 | 出版社官网/CIP | -25% |
| 国家社科基金 | 3项 | 0项主持 | 全国哲学社会科学工作办公室 | -100% |

**红旗**：差异 >20% 的项必须保留原始截图或导出文件作为证据。

### 2.4 学生培养线索检索（产出数量调查的延伸）

| 技术 | 操作 | 揭示的问题 |
|:---|:---|:---|
| 学生毕业审计 | CNKI 学位论文库检索该学者的硕博士论文 | 系统延毕是导师压榨或放羊的强烈信号 |
| 首篇论文时间线 | 查每个学生的入学年份到第一篇合著论文间隔 | >2 年才出第一篇，或仅发普刊，说明指导不足 |
| 招生断档分析 | 查近 5-10 年该学者招生名单 | 连续 2+ 年零招生，往往意味着往届生主动劝退 |
| 学生职业轨迹 | LinkedIn / ResearchGate 搜毕业生去向 | 大量学生彻底离开学界且零产出，是负面信号 |
| 同行私下咨询 | 如有可能，与在读/毕业生私下交流 | 关于抢一作、996、经费克扣的一手信息 |

### 2.5 检查点

- [ ] 已在 CNKI、万方（或 WoS）完成手动检索并导出结果
- [ ] 已建立 CLAIMED vs. VERIFIED 对照表
- [ ] 所有数字均标注具体数据库、检索日期、查询式、结果数
- [ ] 已对学生的毕业年份、首篇论文、职业轨迹进行快速审计
- [ ] 差异 >10% 的项已保存原始截图/导出文件

## Step 3：学术质量深度评估

**目标**：对核心论文进行同行评审式的六维质量评分，识别专业性注水、Salami Slicing、抄袭等不端迹象。

### 3.1 获取关键论文全文

优先获取以下论文的 PDF：
- 学位论文
- 所有 CSSCI/核心期刊论文
- 学者自我声称的"代表作"
- 与学生合著的高可见度论文

将 PDF 放入 `./pdfs/` 目录。

### 3.2 脚本批量文本提取

```bash
# 单篇论文提取
python3 /Users/xiaoy/Downloads/academic-investigation-skill/scripts/text_profiler.py \
  --input ./pdfs/paper_1.pdf \
  --output ./data/paper_1_profile.json

# 如需同时保存原始文本
python3 /Users/xiaoy/Downloads/academic-investigation-skill/scripts/text_profiler.py \
  --input ./pdfs/paper_1.pdf \
  --output ./data/paper_1_profile.json \
  --save-text ./data/paper_1_text.txt
```

`text_profiler.py` 会输出：
- 基本统计（字数、行数）
- 术语频率（政治/学术/理论/方法论分类）
- 原创性标记（如"笔者认为""本文发现"密度）
- 参考文献统计（外文比例、最新引用年份）
- 章节结构（启发式提取的标题）

### 3.3 六维质量评分

#### 单篇评分（人工 + 脚本）

```bash
python3 /Users/xiaoy/Downloads/academic-investigation-skill/scripts/paper_quality_rubric.py \
  --profile ./data/paper_1_profile.json \
  --observations ./data/paper_1_observations.json \
  --output ./data/paper_1_quality.json
```

六维量表（A/B+/B/C/D）及权重：

| 维度 | 权重 | 核心问题 |
|:---|:---:|:---|
| 原创性与重要性 | 25% | 是否提出影响该领域的新理解/新方法/新证据？ |
| 技术严谨性 | 20% | 研究方法是否存在致命缺陷（fatal flaws）？ |
| 数据与证据质量 | 20% | 数据来源、透明度、可重复性、统计处理是否恰当？ |
| 逻辑结构与结论稳健性 | 15% | 结构是否清晰？结论是否与数据匹配？ |
| 文献综述与引用规范 | 10% | 是否恰当引用前人？有无过度自引或遗漏关键文献？ |
| 表达清晰度与可及性 | 10% | 摘要是否清晰？写作是否专业？图表是否自明？ |

#### 批量混合评分（脚本 + LLM）

当论文数量较多时，使用 `hybrid_scorer.py`：

```bash
# 步骤1：脚本提取所有论文的文本统计和节选，生成 LLM review pack
python3 /Users/xiaoy/Downloads/academic-investigation-skill/scripts/hybrid_scorer.py prepare \
  -i ./pdfs \
  -o ./data/hybrid_scores \
  -e 3000

# 步骤2：将 ./data/hybrid_scores/llm_review_request.md 提交给 LLM
# LLM 返回对每篇论文的定性观察，保存为 llm_observations_batch.json

# 步骤3：脚本应用 LLM 观察，输出批量评分与排名
python3 /Users/xiaoy/Downloads/academic-investigation-skill/scripts/hybrid_scorer.py apply \
  -i ./pdfs \
  -o ./data/hybrid_scores
```

最终会得到 `_final_ranked_report.json`，内含每篇论文的六维评分、评级和红旗警告。

### 3.4 专业性红旗审查

在全文细读时，重点检查以下信号：

| 信号 | 检查方法 |
|:---|:---|
| **会议交流稿冒充 CSSCI** | 核查论文体例：是否有摘要、关键词、参考文献、规范脚注。无参考文献的"书面交流"不可计入核心期刊成果。 |
| **学位论文章节拆分过度发表** | 比对博士论文目录与期刊论文内容，标记高度重合的章节。 |
| **方法论声明不实** | 声称"深度访谈""田野调查"但正文中无访谈对象、提纲、编码过程的呈现。 |
| **一稿多投/重复发表** | 逐行比对疑似重复论文的 PDF 文本（可用脚本提取后 diff）。 |
| **抄袭/自我抄袭** | 对高可疑段落进行查重或原文对比。 |
| **图片/数据异常** | 理工科重点检查 gel 条带在不同论文中重复出现、统计值与样本量矛盾。 |

### 3.5 检查点

- [ ] 核心论文 PDF 已收集并放入 `./pdfs/`
- [ ] 已完成 `text_profiler.py` 提取（单篇或批量）
- [ ] 已完成 `paper_quality_rubric.py` 或 `hybrid_scorer.py` 质量评分
- [ ] 对核心期刊论文已完成至少 1 篇全文细读，并形成专业性总评
- [ ] 已记录每篇评分论文的：标题、年份、期刊、评分、评级、主要缺陷
- [ ] 未发现学术不端直接证据时，也明确记录"已核查但无直接证据"

## Step 4：关系网络与资源依赖分析

**目标**：绘制学者的学术社交网络，识别导师依赖、机构主场优势、资源枯竭等模式。

### 4.1 关系网络绘制

| 关系类型 | 信息来源 | 分析要点 |
|:---|:---|:---|
| 导师-学生 | 学位论文致谢、知网合著论文、Tavily API 搜索 | 导师的学术权力、师生合作论文占比、学生独立后产出 |
| 合作者 | 论文合著者名单、科研项目成员 | 是否长期与上级/权威合作？自己是否为 middle/last author？ |
| 机构依赖 | 发表论文的期刊与编辑部任职记录 | 是否存在"机构主场优势"（大量论文发在导师任编委的期刊）？ |
| 基金项目 | 国家自然科学基金大数据门户、省级基金官网 | 近 3 年是否有在研项目？ |

### 4.2 结构化学生评价数据库检索

如有研学网等结构化评价数据库：

```bash
python3 /Users/xiaoy/Downloads/academic-investigation-skill/scripts/review_matcher.py \
  --name "学者姓名" \
  --school "机构名称" \
  --input "/path/to/reviews_database.xlsx" \
  --output ./data/reviews_matched.json
```

脚本会输出：
- 匹配记录数、平均评分、可信度分布
- 14 个维度的情感极性分析
- `investigation_leads`：将匿名评价转化为可验证的具体行动线索

**常见线索映射**：

| 线索类型 | 典型关键词 | 验证动作 | 严重程度 |
|:---|:---|:---|:---:|
| 延毕 | 延毕, 卡毕业, 不让毕业 | 查 CNKI 学位论文实际毕业年份 vs 标准学制 | 高 |
| 抢一作 | 抢一作, 导师一作 | 统计近年学生一作 vs 导师一作比例 | 高 |
| 禁止实习 | 不允许实习, 不让实习 | LinkedIn 查学生实习轨迹 | 中 |
| 高强度压榨 | 打卡, 996, 加班, 周末 | 私下同行咨询 | 中 |
| 经费克扣 | 补助少, 不发工资 | 比对 NSFC 在研项目数 vs 实验室规模 | 中 |
| 放羊 | 放养, 不管学生, 见不到人 | 核对学生近期论文署名与通讯作者频率 | 中 |
| 有毒文化 | 骂人, PUA, 压榨, 威胁 | 增加私下咨询权重，验证具体事件 | 高 |

### 4.3 导师/学者原型判断（辅助启发式）

根据观察到的行为模式，可映射到以下原型（仅供模式识别，非诊断）：

| 原型 | 可观察信号 | 调查意义 |
|:---|:---|:---|
| 公司老板 | 大量横向项目、学生当员工用、论文次要 | 解释低学术产出但团队庞大；存在剥削风险 |
| 放羊人 | 很少见学生、无固定组会、学生自生自灭 | 解释论文质量参差、主题不一致 |
| 推土机 | 高频组会、高压产出要求、快速周转 | 可能高产但伴随高流失率 |
| 善意赞助人 | 保护学生一作、提供资源人脉 | 正面范例；解释稳定的学生出路 |
| 寻租地主 | 抢学生一作、派杂活、严控经费 | 与署名剥削、履历包装直接相关 |
| 牌面长老 | 头衔高但实际不管事、日常由中层代管 | 学生的真实贡献可能被中间人侵占 |
| 项目企业家 | 开公司、把学生劳力导向商业项目 | 解释延毕和论文主题偏离 |

### 4.4 检查点

- [ ] 已绘制导师-学生-合作者三角关系图
- [ ] 已统计近 5 年学生一作论文比例
- [ ] 已核查导师/学者是否在目标期刊担任编委（如有"机构主场优势"嫌疑）
- [ ] 已查询 NSFC 大数据门户（手动），记录在研项目数
- [ ] 如有评价数据库，已运行 `review_matcher.py` 并审查生成的 `investigation_leads`

## Step 5：异常检测与深度挖掘

**目标**：在时间轴和同行对比中发现不寻常模式，验证学历、职称、奖项的真实性。

### 5.1 晋升时间轴异常

建立同侪对照组（peer cohort），比较晋升速度：

| 学者 | 入职年份 | 副教授 | 教授 | 备注 |
|:---|:---:|:---:|:---:|:---|
| 张三 | 2007 | 2017 | — | 间隔 10 年，正常偏慢 |
| 李四（同门） | 2008 | 2013 | 2018 | 明显更快 |
| 王五（同事） | 2009 | 2014 | 2019 | 正常速度 |

**红旗**：晋升速度显著慢于同侪且无合理解释；或某一年突然集中爆发多篇论文后随即晋升。

### 5.2 论文发表时间聚类

检查是否存在以下模式：
- **晋升前 6 个月内突击发表 3+ 篇论文**
- **导师升职/获奖后，学生论文突然激增**
- **早期论文质量尚可，近 5 年断崖式下跌至低质期刊**

### 5.3 履历表述升级检测（数字足迹考古）

利用互联网档案馆（Wayback Machine）追踪学者机构主页和 CV 的历史版本：

1. 在 `web.archive.org` 输入学者机构主页 URL，获取 5 年、10 年前的快照。
2. 将历年简历中的关键字段（学位、职称、论文数、海外经历）整理成表格。
3. 标记"无增量支撑的表述升级"：
   - 同一海外经历从"访问学者"升级为"博士后"
   - 论文数从"60余篇"自动变为"80余篇"但数据库仅增加 2 篇
   - 某"特聘教授"头衔突然出现但机构官网无聘任公告

### 5.4 微信公众号补充线索验证

如 Step 1 的微信公众号搜索发现了著作宣传、机构新闻或其他传言：

- **著作宣传**：核对 CIP 数据、出版社官网、京东/当当 ISBN，验证作者署名和出版年份。
- **职称/头衔宣传**：回查机构官网和正式聘任文件，验证宣传中的职称是否属实。
- **未证实传言**：记录具体内容，在后续步骤中通过学位论文、项目公示、新闻报道等渠道交叉验证。**传言本身不得写入主报告结论**。

### 5.5 检查点

- [ ] 已建立至少 2-3 人的同侪晋升对照表
- [ ] 已检查论文发表时间是否存在晋升前/奖项前突击聚集
- [ ] 已利用 Wayback Machine 查看至少 1 个历史版本的机构主页或 CV
- [ ] 已核对海外经历、特聘头衔、奖项的颁发机构记录
- [ ] 每个异常信号均标注了置信度（低/中/高/极高）及推理依据

## Step 6：多来源交叉验证

**目标**：确保每一个可能损害声誉的发现都有 ≥2 个独立来源支撑。

### 6.1 来源可靠性层级

| 层级 | 来源类型 | 可靠性 |
|:---:|:---|:---:|
| 1 | 官方机构记录（聘任公示、学位论文、官方目录） | ⭐⭐⭐⭐⭐ |
| 2 | 学术数据库（CNKI、万方、WoS） | ⭐⭐⭐⭐⭐ |
| 3 | 第三方评估（教育部公示、基金委公告） | ⭐⭐⭐⭐☆ |
| 4 | 大规模结构化评价数据库 | ⭐⭐⭐☆☆ |
| 5 | 主流媒体报道 | ⭐⭐⭐☆☆ |
| 6 | 社交媒体（知乎、小红书、微博） | ⭐⭐☆☆☆ |
| 7 | 零散匿名评价、微信公众号 | ⭐☆☆☆☆ |

### 6.2 独立性检查规则

两个来源只有在**不来自同一原始材料**时才算独立：
- ❌ **不独立**：新闻报道引用学者 CV，与 CV 本身视为同一来源。
- ✅ **独立**：CNKI 论文列表 + 机构官网聘任公示。
- ✅ **独立**：学位论文 PDF + 教育部基金立项公示。

### 6.3 公开声誉采集清单

| 平台 | 检索词 | 预期信号 | 可靠性 |
|:---|:---|:---|:---:|
| 导师评价网 | `导师姓名 + 学校` | 学生投诉、署名剥削、延毕 | ⭐☆☆☆☆ |
| 知乎/小红书 | `导师姓名 + 读研体验 / 实验室 / 避雷` | 非正式同辈经验 | ⭐☆☆☆☆ |
| 微信公众号 | `导师姓名` | 著作宣传、机构 gossip、传言 | ⭐☆☆☆☆ |
| ResearchGate / LinkedIn | 毕业生去向 | 职业轨迹、离开学界比例 | ⭐⭐☆☆☆ |

**证据标准**：每一个来自匿名/低可靠来源的指控，必须记录平台名称、发帖日期、精确 URL 或截图文件名。在写入主报告前，必须通过可验证的公开记录交叉确认。

### 6.4 检查点

- [ ] 每一个"红旗"或负面发现均有 ≥2 个独立来源
- [ ] 已建立编号式的来源索引表（对应报告附录）
- [ ] 所有社交媒体/匿名平台信息仅作为假设生成器，未单独构成指控
- [ ] 来源冲突的地方已明确记录并降级置信度
- [ ] 已记录"负面搜索"（查无此信息）的具体检索条件

## Step 7：综合研判与报告生成

**目标**：基于全部证据链，撰写两面平衡、来源清晰、带有免责声明的最终报告。

如有缺失字段，脚本会标红；`--fix` 会自动填充默认值，但仍需人工审查。

### 7.2 生成报告 Prompt

```bash
python3 /Users/xiaoy/Downloads/academic-investigation-skill/scripts/investigate.py prompt \
  --data ./scholar_data.json \
  --template /Users/xiaoy/Downloads/academic-investigation-skill/scripts/report_template.md \

  --output ./report_prompt.md
```

脚本会将 `scholar_data.json` 的核心发现注入 `report_template.md` 的占位符中，生成一份针对目标 LLM 优化过的 prompt。

### 7.3 LLM 撰写与人工审校

将 `./report_prompt.md` 提交给 LLM，由 LLM 生成 Markdown 格式的深度报告。**人类必须完成以下审校**：

1. **两面性检查**：每一段批评是否都对应至少一段肯定？
2. **证据链检查**：报告中的每一个数字、日期、职称是否都能在附录来源索引中找到对应？
3. **措辞检查**：避免"学术造假""抄袭"等定罪式表述，除非有直接证据；改用"存在注水嫌疑""专业性深度有限"等基于证据的推断。
4. **微信公众号来源检查**：如引用了微信公众号内容，确认来源栏仅写"微信公众号"，未出现任何工具名称。
5. **免责声明检查**：确认最终报告包含固定免责声明。

### 7.4 报告标准结构

```markdown
1. 执行摘要（核心发现 + 关键证据等级表）
2. 基本信息与教育背景（履历表 + 教育时间轴 + 分析）
3. 学术成果审查（论文产出 + 专著 + 批量质量评分 + 重点论文细评 + 科研项目）
4. 往届学生评价汇总（数据库检索结果 + 间接描述）
5. 核心发现（同门对比 + 合作者分析 + 宣传口径问题 + 异常信号）
6. 综合评价（两面性分析 + 一句话定性）
7. 调查局限性（明确列出无法核实的内容）
8. 附录：数据来源索引（编号表格）
9. 免责声明
```

## 扩展模块（按需启用）

### A. 行政职务-产出耦合分析
适用：学者有副院长/系主任/学科带头人等行政职务时。
- 分析其担任行政职务期间，本人及团队的论文发表是否存在异常激增。
- 检查所主管期刊/会议是否存在"自产自销"迹象。

### B. 机构主场优势量化
适用：学者长期在同一机构任职，且大量论文发在本土期刊。
- 统计其顶级论文中，编委/审稿人来自同一学术网络的比例。
- 对比同机构其他学者的期刊分布，判断是否存在"主场保护"。

### C. 从论文往上下游延伸
适用：需要评估学者对领域的真实贡献时。
- 查核心论文的被引质量（谁在引？是第三方还是自引/互引小圈子？）
- 查基金项目结题报告中的论文清单，是否与公开数据库一致。

### D. 学术影响力刷量检测
适用：学者 h-index 或引用量看起来异常高时。
- 计算自引率、团队互引率、引用者机构集中度。
- 识别是否存在"引用卡特尔"（citation cartel）。

### E. 语言风格计量学与代笔检测
适用：怀疑存在 ghostwriting 时。
- 收集学者 5-10 篇基线论文 + 1-3 篇可疑论文。
- 运行 `stylometry_profiler.py` 计算句长、功能词密度、自我指称密度的相似度矩阵与 PCA 投影。
- 风格突变或与学生风格高度重合是红旗信号。

### F. 商业利益网络与经费 footprint
适用：学者有企业兼职、公司或大量横向项目时。
- 天眼查/企查查检索其名下的企业关联。
- 核对专利发明人名单与学生团队成员的重叠度。
- 标记项目经费日期与相关论文提交日期的密集耦合。

### G. 数字足迹考古
适用：发现学者履历存在多个版本时。
- 用 Wayback Machine 捕获历年机构主页快照。
- 提取学位、职称、论文数等字段，制作年度 diff 表。
- 标记"无增量支撑的表述升级"。
