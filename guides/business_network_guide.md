# 商业利益网络与经费 footprint 分析操作手册

本手册对应 `SKILL.md` 扩展模块 F。无需脚本，全部通过公开数据库查询和手工记录完成。

---

## 一、调查目标

识别学者是否存在以下三种套利行为：
1. **隐蔽产学研身份**：持股或任职于某企业，但在学术发表中未披露利益冲突。
2. **学生劳动企业化**：学生专利、论文成果流向学者关联企业。
3. **疑似横向项目转化为学术产出的套利迹象**：以横向项目经费支持的课题，产出以学术名义发表，但结论偏向企业利益。

## 二、查询工具与入口

### 2.1 工商信息查询

| 平台 | 网址 | 免费功能 | 付费/登录功能 |
|:---|:---|:---|:---|
| 天眼查 | `tianyancha.com` | 基础企业信息、股权结构预览 | 深层关联、历史变更、导出报告 |
| 企查查 | `qcc.com` | 企业搜索、股东高管名单 | 关联图谱、批量导出 |
| 国家企业信用信息公示系统 | `gsxt.gov.cn` | 官方注册信息、年报 | 需验证码，无批量功能 |

**推荐组合**：天眼查/企查查做初步筛查 → 国家企业信用信息公示系统做官方确认。

### 2.2 专利查询

| 平台 | 网址 | 功能 |
|:---|:---|:---|
| 国家知识产权局专利检索系统 | `pss-system.cponline.cnipa.gov.cn` | 官方检索，需注册 |
| 佰腾网 | `baiten.cn` | 免费查专利发明人、申请人 |
| Soopat | `soopat.com` | 高级检索、法律状态 |

### 2.3 横向项目查询

| 来源 | 查询方式 | 可获得信息 |
|:---|:---|:---|
| 学者所在单位官网 | 搜索"横向项目""科技成果转化""产学研合作" | 项目公示、合作协议签约新闻 |
| 中国招标投标公共服务平台 | `cebpubservice.com` | 部分大额横向项目招标公告 |
| 国家自然科学基金委员会 | `nsfc.gov.cn` → 项目查询 | 国自然项目信息（非横向，但可对比） |

## 三、分步操作指南

### 步骤 1：锁定同名企业（工商信息）

#### 3.1.1 检索策略
以学者**全名 + 所在城市**为关键词在天眼查/企查查检索。

**示例**：
- 主检索：`张三 北京`
- 补充检索：`张三 某机构名`（部分企业会含机构关键字）

#### 3.1.2 去重与确认（关键！）
同名同地者众多，必须建立**确认清单**。对每一个疑似企业，回答以下问题：

| 确认项 | 判定方法 | 结果 |
|:---|:---|:---:|
| 经营范围相关 | 企业经营范围是否包含学者研究领域关键词？ | 是/否 |
| 专利关联 | 该企业专利的发明人中是否有学者学生/同事？ | 是/否 |
| 地址关联 | 企业注册地址是否与学者单位地址接近？ | 是/否 |
| 联系方式关联 | 企业公开电话/邮箱是否与学者单位一致？ | 是/否 |
| 时间关联 | 企业成立时间是否与学者某段任职/项目时间重叠？ | 是/否 |

**确认标准**：至少满足 **3 项"是"**，方可将该企业纳入正式调查对象。

#### 3.1.3 记录模板
为每个确认企业建立独立记录：

```markdown
### 企业名称：[XXX科技有限公司]
- 统一社会信用代码：
- 注册地址：
- 成立日期：
- 当前状态（存续/注销/吊销）：
- 经营范围：

#### 学者关联
- 关联类型：股东 / 董事 / 监事 / 法定代表人 / 无直接工商登记但通过亲属控制
- 持股比例：
- 任职起止时间：
- 历史变更记录（何时新增/退出）：

#### 亲属穿透（如有）
- 关联亲属姓名：
- 亲属持股比例：
- 与学者关系：配偶 / 子女 / 父母 / 兄弟姐妹

#### 确认依据
1. 天眼查截图（文件名：`tyc_张三_XXX_20260415.png`）
2. 国家企业信用信息公示系统截图（文件名：`gsxt_张三_XXX_20260415.png`）
3. 其他佐证：
```

### 步骤 2：专利发明人映射

#### 3.2.1 检索策略
以步骤1确认的企业为"申请人"，在国家知识产权局或佰腾网进行专利检索。

**检索式示例**：
```
申请人：(XXX科技有限公司)
发明人：(张三 或 李四 或 王五)
```

#### 3.2.2 分析维度
对检索到的每件专利，记录：

| 字段 | 说明 |
|:---|:---|
| 专利号 | |
| 专利名称 | |
| 申请日 | 精确到日 |
| 公开/授权日 | |
| 申请人 | 企业全称 |
| 发明人列表 | 全部发明人，按顺序 |
| 与学者关系 | 学者本人 / 学生 / 同事 / 无关联 |
| 技术主题 | 用3-5个关键词概括 |

#### 3.2.3 时间耦合分析
将专利**申请日**与学者团队**相关论文的投稿/录用日期**进行并列对比：

```markdown
| 专利号 | 申请日 | 相关论文标题 | 投稿/录用日期 | 时间差 | 耦合信号 |
|:---|:---|:---|:---|:---:|:---|
| CN2020... | 2020-03-15 | 《某技术经济分析》 | 2020-05-20（录用） | +66天 | 专利先于论文，疑似专利成果转化论文 |
```

**红旗信号**：专利申请日早于相关论文投稿日 180 天内，且技术主题重合度 ≥70%。

---

### 步骤 3：论文结论偏向性审查

#### 3.3.1 筛选待审论文
从学者论文清单中，筛选出与确认企业**所在行业直接相关**的论文。建议采用以下标准：
- 论文标题、摘要、关键词中包含该行业的核心术语
- 论文发表时间在学者与企业存在关联期间

#### 3.3.2 四维度审查表
对每篇待审论文，填写以下表格：

```markdown
### 论文：[标题]
- 发表期刊：
- 发表年份：
- 与企业关联时期：

| 维度 | 发现 | 红旗？ |
|:---|:---|:---:|
| **资助声明** | 论文致谢/脚注中是否提及企业资助？ | 未提及→🟡 |
| **数据来源** | 是否使用企业内部数据/调研样本？ | 使用但未说明→🔴 |
| **结论方向** | 结论是否对企业/行业有利？ | 一边倒有利→🟡 |
| **风险提示** | 是否讨论了该技术/政策/行业的负面效应？ | 完全回避→🟡 |
```

**判定原则**：
- **🔴 高危险**：数据来源未说明 + 结论一边倒
- **🟡 中危险**：资助未披露 或 结论过度乐观但数据公开
- **🟢 正常**：资助已披露、数据来源公开透明、结论有正有负

### 步骤 4：横向项目 footprint 追踪

#### 3.4.1 信息收集渠道
优先从以下渠道收集横向项目信息：
1. 学者所在单位官网的"产学研合作""科技成果转化"栏目
2. 学者所在学院的年度工作总结/新闻稿
3. 合作企业的招股说明书、年报（如有上市）
4. 学术会议的产学研签约新闻报道

#### 3.4.2 记录模板
```markdown
### 项目名称：[XXX技术研发]
- 合作企业：[名称]
- 合同金额（如有）：
- 项目起止时间：
- 到账时间（关键！）：
- 主要参与人：
- 项目成果形式：专利 / 论文 / 研究报告 / 产品样机

#### 关联论文
| 论文标题 | 投稿/录用日期 | 与到账时间差 | 关联度评估 |
|:---|:---|:---:|:---|
| | | | 直接相关 / 间接相关 / 无关联 |
```

#### 3.4.3 耦合判定标准
- **强耦合**：横向项目到账后 6 个月内，学者团队发表 ≥2 篇直接相关论文
- **中耦合**：到账后 6-12 个月内，发表 1 篇直接相关论文
- **弱耦合/正常**：超过 12 个月或无直接关联

## 五、常见陷阱与排除方法

| 陷阱 | 排除方法 |
|:---|:---|
| **同名不同人** | 必须完成3.1.2的5项确认清单，缺一不可 |
| **正当产学研合作被误伤** | 公开披露、数据透明、结论平衡的合作不属于红旗 |
| **学生自主创业** | 若企业由学生独立创办且与学者无股权关联，不纳入学者利益网络 |
| **退休返聘顾问** | 若学者已退休且企业任职在退休后，需降低信号权重（除非仍在学术岗位发表未披露论文） |
