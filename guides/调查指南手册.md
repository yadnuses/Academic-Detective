## 一、你和 LLM 怎么配合

学术侦探是**半自动调查系统**。LLM 不会自动完成一切——它需要你喂数据、给方向、做判断。

```
你说                          LLM 做
─────────────────            ─────────────────
"查一下张教授 某大学"          → 初始化案件、搜索官网、建立基础画像
"他的知网论文我导出了 Excel"    → 导入数据、统计产出、对比声称
"这几篇论文 PDF 给你"          → 六维评分、写作风格分析
"他2022年突然发了很多论文"      → 深挖产出突增原因、检测异常模式
"学生评价怎么样"               → 匹配研学网数据、搜索舆情
"生成报告"                    → 汇总证据链、输出 Markdown/PDF
```

**关键原则**：
- 你给的信息越多，LLM 的分析越准
- 你提的问题越具体，LLM 的深挖越有针对性
- 你不做判断，LLM 只能给你数据，不能给你结论

## 二、四种调查场景的开场方式

### 场景 A：标准背调（选导师前查一查）

```
你：查一下 [姓名] [学校]
```

LLM 会自动：
- 搜索机构官网，提取基本信息
- 搜索学术数据库，初步统计论文
- 生成基础画像和职业时间线
- 输出初步调查报告

**示例**：
```
你：查一下陈志远 东方理工大学
```

### 场景 B：有明确疑点（针对性深挖）

```
你：查一下 [姓名] [学校]，重点关注 [具体疑点]
```

**示例**：
```
你：查一下林晓峰 星辰科技学院，他官网上列了5个社会兼职头衔，
    我怀疑有些是假的
```

LLM 会：
- 正常执行基础调查
- 额外验证你提到的每个头衔
- 对每个头衔给出"已验证/未找到/存疑"的结论

### 场景 C：舆情关联调查（有公开事件）

```
你：查一下 [姓名] [学校]，最近 [事件概述]
```

**示例**：
```
你：查一下周敏慧 南方医科大学附属医院，她的研究生最近坠江了，
    网上有遗书说导师压榨
```

LLM 会：
- 搜索事件相关报道和讨论
- 交叉验证遗书真实性
- 分析时间线和多方说法
- 同时进行学术产出核查

### 场景 D：批量筛查（多个对象）

```
你：帮我查以下几位导师：
    - 张教授 某大学
    - 李教授 另一所大学
    - 王教授 第三所大学
    先做快速筛查，有疑点的再深挖
```

LLM 会：
- 对每位导师执行 Step 1-2（基础画像 + 产出核实）
- 标记有异常信号的导师
- 等你确认后再对重点对象深入调查

## 三、七步框架：每一步你该说什么

### Step 1：基础画像

**你说**：`查一下 [姓名] [学校]`

**LLM 产出**：
- 基础身份档案表（姓名、职称、导师类型、研究方向）
- 教育与职业时间线
- 来源可信度标注（⭐1-5）

**你看完后说**：
- ✅ 如果信息完整：`好的，继续下一步`
- ⚠️ 如果有模糊点：`他的博士导师是谁？能查到吗？`
- ❌ 如果有错误：`不对，他2020年就升副教授了，不是讲师`

**真实案例参考**：

> **案例 A（陈志远）**：用户只说了"查一下陈志远 东方理工大学"，LLM 自动搜索官网、教师主页、学院领导页，产出了完整的身份档案和职业时间线。用户看到后直接说"继续"。
>
> **案例 B（方启明）**：用户提供了方启明的官网链接和12篇论文PDF。LLM 首先生成了基础画像，发现"博士学位信息严重缺失（官网层面）"，主动标记为待核实项。用户随后提供了博士论文PDF，LLM 通过致谢部分确认了导师信息。

---

### Step 2：学术产出数量核实

**你说**：
- `他的论文你搜到了多少？`（让 LLM 自己搜索）
- `我把知网导出的 Excel 给你`（提供数据让 LLM 分析）
- `他说自己发了80篇论文，帮我核实一下`（给出声称值让 LLM 对比）

**LLM 产出**：
- CLAIMED vs VERIFIED 对照表
- 论文清单（标题、期刊、年份、作者排序）
- 基金项目清单
- 差异分析（声称 X 篇，核实 Y 篇，差距 Z）

**你看完后说**：
- `这些论文里有没有期刊特别差的？`（触发期刊质量分析）
- `他的论文都是独著还是有合作者？`（触发作者网络分析）
- `帮我把这些论文PDF都评一下分`（进入 Step 3）

**真实案例参考**：

> **案例 C（林晓峰）**：LLM 搜索后发现林晓峰只有5篇论文，其中3篇发表在《现代传媒研究》《文化产业论坛》等低门槛收费期刊。用户追问"这些期刊正规吗"，LLM 随即查到了期刊的版面费（3000-5200元）、网友评价（"水刊"）、影响因子（0.04）等信息。
>
> **案例 D（周敏慧）**：用户提供了50篇论文PDF。LLM 统计后发现：声称"80余篇"中，第一作者仅8篇（16.3%），通信作者5篇（10.2%），其余71.4%为挂名/参与。用户看到后说"把第一作者的论文重点评一下"。

---

### Step 3：质量评估（六维评分）

**你说**：
- `帮我评一下这些论文的质量`
- `重点评这几篇 CSSCI 的`（指定范围）
- `用六维评分框架打个分`

**LLM 产出**：
- 六维评分表（原创性/严谨性/证据/逻辑/文献/表达）
- 能力天花板分析（最高能到什么水平）
- 分群统计（CSSCI 均分 vs 普刊均分）

**你看完后说**：
- `脚本评分有没有偏差？帮我人工校准一下`
- `那篇 B+ 的论文具体好在哪？`（触发详细分析）
- `有没有发现代笔或抄袭的迹象？`（触发写作风格分析）

**真实案例参考**：

> **案例 E（沈逸文）**：LLM 对19篇论文全部完成了六维评分。用户随后要求"人工复评脚本评分"，LLM 发现脚本存在3处偏差：误检参考文献为0条（实际36条）、未识别章节结构、对理论评论类论文"数据证据"维度评分偏低。校准后综合分上调了9分。
>
> **案例 F（某虚构学者）**：脚本评分显示所有论文都在60-65分（C级），用户追问"有没有哪篇明显好于其他的"，LLM 发现博士论文（67.9/B）明显高于期刊短文（61-64/C），指出该学者呈现"一篇博士论文为核心，多篇短篇衍生论文为外围"的形态。

---

### Step 4-5：关系网络 + 异常检测

**你说**：
- `帮我画一下他的学术关系网络`
- `有没有什么异常信号？`
- `他和学生的关系怎么样？`（触发师生网络分析）

**LLM 产出**：
- 交互式网络图（D3.js HTML）
- 异常规则触发列表（C01-C07）
- 师生关系分析

**你看完后说**：
- `他2022年突然发了12篇，正常吗？`（引导深挖 C01）
- `他的学生论文都挂他一作吗？`（引导深挖 C04）
- `这个网络图里怎么没有 XX？`（补充信息）

**真实案例参考**：

> **案例 G（周敏慧）**：LLM 检测到 C04（作者排序异常）——其指导的研究生以一作在《中华临床医学杂志》发表论文，周敏慧署名末尾。用户追问"这是不是说明学生能力不错"，LLM 分析后指出：在医学领域，导师挂末尾（通讯作者位）是正常模式，但需要结合学生遗书中"导师禁止使用课题组数据写毕业论文"的指控来综合判断。

---

### Step 6：多源验证

**你说**：
- `学生评价怎么样？`
- `帮我搜一下有没有负面信息`
- `研学网上有他的评价吗？`

**LLM 产出**：
- 研学网评价匹配结果
- 舆情搜索结果
- 信息空白记录（"0条匹配"也是数据）

**你看完后说**：
- `小红书上有没有人说过他？`（扩展搜索范围）
- `这些负面评价可信吗？有没有交叉验证？`
- `没有评价是不是说明他很低调？`（引导 LLM 分析信息空白的含义）

---

### Step 7：报告生成

**你说**：
- `生成报告吧`
- `把所有发现汇总成一个报告`
- `出个 PDF`

**LLM 产出**：
- 完整调查报告（Markdown）
- 风险评估总表
- 证据来源清单
- PDF 版本（含自动图表）

**你看完后说**：
- `风险评级调一下，XX 维度应该是中风险不是低风险`
- `待核实事项里加上 XX`
- `可以了，谢谢`

## 四、真实案例复盘：三种调查深度

### 案例 1：快速筛查（30分钟）

**背景**：用户想快速了解某导师的基本情况。

```
你：查一下陈志远 东方理工大学

LLM：[搜索官网、教师主页，生成基础画像]
     [搜索 ResearchGate、知网，统计论文]
     [生成初步调查报告]

产出：
  - 基础画像表 ✅
  - 论文统计（17篇，211次引用）✅
  - 风险评级：中低风险 ✅
  - 待核实6项 ✅

你：好的，够了，谢谢
```

**关键**：快速筛查只做 Step 1-2，够用就行。

---

### 案例 2：标准调查（2-3小时）

**背景**：用户要认真调查某导师，需要完整的学术档案。

```
你：查一下沈逸文 江南大学人文学院

LLM：[Step 1] 生成基础画像、教育时间线
     [Step 2] 搜索知网，找到10篇论文
     → 输出初步调查报告

你：这些论文质量怎么样？帮我评分

LLM：[Step 3] 对10篇论文进行六维评分
     → 输出质量评估报告
     → 发现能力天花板为 B+ 级（75分）

你：有没有代笔或抄袭的迹象？

LLM：[Step 3 补充] 运行写作风格计量分析
     → 19篇文档语言指纹一致，无代笔迹象

你：他的导师是谁？能查到吗？

LLM：[Step 4] 搜索硕博论文致谢
     → 硕士导师：何正则教授
     → 博士导师：刘思远教授

你：学生评价呢？

LLM：[Step 6] 匹配研学网数据
     → 0条匹配，无评价

你：生成报告吧

LLM：[Step 7] 汇总所有发现
     → 输出完整调查报告 + PDF
```

**关键**：每一步都是你主动推进的。LLM 不会自动跳到下一步——它等你确认或追问。

---

### 案例 3：深度调查（多轮深挖，1-2天）

**背景**：用户发现某导师有明确疑点，需要反复深挖。

```
你：查一下林晓峰 星辰科技学院，他官网上列了5个社会兼职头衔，我怀疑有些是假的

LLM：[Step 1] 生成基础画像，列出5个头衔
     [Step 2] 搜索论文，找到5篇
     → 输出初步调查报告

你：那5个头衔帮我一个一个核实

LLM：[Step 6 补充] 逐个验证头衔
     → 省语言艺术协会理事：第一届、第二届名单中均未找到 ⚠️
     → 市语言艺术协会理事：两届名单中均未找到 ⚠️
     → 某国际博览会主持人：所有报道均指向建筑设计领域 ⚠️
     → 某省艺考评委：无公开记录 ⚠️
     → 朗诵考级十级辅导教师：门槛不高，但表述有误导性 ⚠️

你：5个头衔都存疑？论文呢？质量怎么样？

LLM：[Step 3] 对2篇论文进行详细审查
     → 发现作者简介性别错误（标注"男"，实际为女性）⚠️
     → 两篇论文均为3页短评，0-1条参考文献
     → 发表在低门槛收费期刊（版面费3000-5200元）

你：学历呢？他说是硕士

LLM：[Step 1 补充] 深挖学历
     → 2014年毕业于东方艺术学院（硕士）
     → 但2015年仍以"南艺学生"身份参与活动 ⚠️
     → 知网未检索到硕士论文

你：生成报告吧

LLM：[Step 7] 汇总所有发现
     → 综合风险评级：中高
     → 核心风险：5项头衔全部无法验证、论文质量极低、学历时间线存在矛盾
```

**关键**：深度调查的特点是**多轮追问**。每一轮 LLM 产出新发现，你根据发现决定下一步追问方向。

## 五、LLM 产出的中间文件说明

调查过程中 LLM 会生成多种中间文件，了解它们的用途有助于你引导调查方向：

| 文件类型 | 内容 | 何时生成 | 你能用它做什么 |
|:---|:---|:---|:---|
| `config.yaml` | 案件配置 | 初始化时 | 检查 LLM 是否正确理解了调查对象 |
| `scholar_data.json` | 结构化学者数据 | Step 2 后 | 导出给其他工具分析 |
| `CLAIMED_vs_VERIFIED.md` | 声称 vs 核实对照表 | Step 2 后 | 快速看差距有多大 |
| `论文审查报告.md` | 单篇论文详细审查 | Step 3 后 | 看具体哪篇论文有问题 |
| `六维评估报告.md` | 质量评分详情 | Step 3 后 | 看能力天花板在哪 |
| `network.html` | 交互式关系网络图 | Step 4 后 | 浏览器打开，直观查看关系 |
| `异常检测结果.md` | 触发的异常规则 | Step 5 后 | 快速定位风险点 |
| `*_FINAL.md` | 最终调查报告 | Step 7 后 | 完整证据链汇总 |
| `*.pdf` | PDF 报告 | Step 7 后 | 正式交付物 |

## 六、如何引导 LLM 深挖

当你在报告中发现疑点，可以用以下方式引导 LLM 继续深挖：

### 方式 1：直接追问

```
你：他2022年突然发了12篇论文，年均才3篇，这正常吗？
```

LLM 会：
- 分析2022年论文的具体情况
- 检查是否是同一期刊集中发表
- 检查是否有学生批量产出的情况
- 与学科基准线比对

### 方式 2：提供新信息

```
你：我找到了他的硕士论文，PDF在这里：[文件路径]
```

LLM 会：
- 提取论文内容
- 与已发表论文比对（检测自我抄袭/拆分发表）
- 分析写作风格一致性
- 更新基础画像

### 方式 3：指定深挖方向

```
你：重点查一下他的基金项目，国自然那个项目号帮我核实一下
```

LLM 会：
- 搜索国自然数据库
- 核实项目编号、名称、金额、起止时间
- 检查基金与论文的对应关系

### 方式 4：挑战 LLM 的结论

```
你：你说他风险低，但是他的学生评价全是负面的，这怎么解释？
```

LLM 会：
- 重新审视风险评级
- 将学生评价纳入综合评估
- 可能调整风险等级

### 方式 5：要求对比分析

```
你：把他和同学院的李教授对比一下，看看产出差距
```

LLM 会：
- 对两位学者进行并行分析
- 对比论文数量、质量、基金、学生培养等维度
- 生成对比表格

## 七、常见话术模板

### 开场

| 你想要 | 你说 |
|:---|:---|
| 快速了解 | `查一下 [姓名] [学校]` |
| 重点深挖 | `查一下 [姓名] [学校]，重点关注 [疑点]` |
| 批量筛查 | `帮我查以下几位导师：[列表]，先做快速筛查` |
| 继续之前的调查 | `继续 [姓名] 的调查，上次做到 [哪一步] 了` |

### 推进调查

| 你想要 | 你说 |
|:---|:---|
| 进入下一步 | `好的，继续下一步` |
| 深入当前步骤 | `这个再深挖一下` |
| 补充信息 | `我找到了 [XX]，给你看看` |
| 纠正错误 | `不对，[正确信息]` |
| 跳过某步 | `这步跳过，直接做 [下一步]` |

### 深挖疑点

| 你想要 | 你说 |
|:---|:---|
| 验证头衔 | `这个头衔帮我查一下是不是真的` |
| 核实论文 | `这篇论文帮我仔细看看有没有问题` |
| 查基金 | `他的国自然项目帮我核实一下` |
| 看评价 | `学生评价怎么样？` |
| 查舆情 | `有没有负面信息？` |
| 对比分析 | `把他和 [另一位学者] 对比一下` |

### 生成报告

| 你想要 | 你说 |

## 八、避坑指南

### 1. 不要只说"查一下"就不管了

```
❌ 你：查一下张教授 某大学
   [然后什么都不说]

✅ 你：查一下张教授 某大学
   LLM：[产出初步报告]
   你：论文质量怎么样？/ 学生评价呢？/ 有没有异常？
```

**原因**：LLM 的初步报告只是起点。你需要看完后决定追问方向。

### 2. 不要跳过 Step 1 直接要报告

```
❌ 你：直接给我张教授的调查报告

✅ 你：查一下张教授 某大学
   [逐步推进]
   你：生成报告吧
```

**原因**：没有数据就没有报告。LLM 需要先搜索、分析，才能生成有意义的报告。

### 3. 不要忽视"0条匹配"

```
❌ 你：研学网没有评价，那跳过吧

✅ 你：研学网没有评价，这说明什么？
   LLM：可能是新晋导师尚无评价，也可能是信息被清理...
```

**原因**：信息空白本身是数据。在某些情况下，"查不到"比"查到了"更重要。

### 4. 不要只看数字不看内容

```
❌ 你：他有50篇论文，不错啊

✅ 你：这50篇论文都是什么质量？有没有挂名的？
   LLM：[分析后发现] 第一作者仅8篇，其余为挂名/参与...
```

**原因**：论文数量不等于学术能力。需要看作者排序、期刊质量、实际贡献。

### 5. 不要轻信 LLM 的自动结论

```
❌ LLM：综合风险评级：低风险
   你：好的

✅ LLM：综合风险评级：低风险
   你：等等，他的学生评价都是负面的，这怎么解释？
```

**原因**：LLM 的结论基于它能获取的信息。如果你有额外信息（比如你听说的传言），应该告诉 LLM，让它重新评估。

## 附录：一次完整调查的对话流

以下是一次标准调查的完整对话示例（虚构案例）：

```
你：查一下赵教授 华东某大学计算机学院

LLM：[Step 1] 基础画像已生成。
     姓名：赵教授 | 职称：教授 | 导师类型：博导
     研究方向：人工智能、机器学习
     教育背景：A大学本科 → B大学硕士 → C大学博士
     初步调查报告已保存。

你：论文呢？搜到了多少？

LLM：[Step 2] 检索完成。
     - 知网：中文期刊论文23篇
     - Web of Science：SCI论文8篇
     - 声称"发表论文50余篇"，核实31篇，差距19篇 ⚠️
     - 基金：国自然面上1项（在研）、省基金2项（已结题）
     CLAIMED vs VERIFIED 对照表已生成。

你：31篇和50篇差距不小。这些论文质量怎么样？

LLM：[Step 3] 对8篇SCI论文进行了六维评分。
     - 最高分：78.5/B+（IEEE TPAMI）
     - 最低分：62.3/C（某开源期刊）
     - 平均分：69.2/B
     - 能力天花板：B+级
     详细评分表已生成。

你：有没有代笔或者学生全干的活？

LLM：[Step 3 补充] 分析了作者网络。
     - 8篇SCI中，学生一作+赵教授通讯的有5篇
     - 赵教授独立一作的有3篇
     - 写作风格计量分析：所有论文语言指纹一致，无代笔迹象
     结论：属于正常的导师-学生合作模式。

你：学生评价呢？

LLM：[Step 6] 匹配完成。
     - 研学网：2条评价（1正面、1中性）
     - 正面："赵老师很负责，每周都和学生讨论"
     - 中性："要求比较高，论文修改很仔细"
     - 小红书/知乎：未检索到负面信息

你：有没有什么异常信号？

LLM：[Step 5] 异常检测完成。
     - C01 产出突增：2021年发表8篇（年均3篇），触发 ⚠️
     - C03 期刊集中：无异常 ✅
     - C04 作者排序：无异常 ✅
     - C06 时间线矛盾：无异常 ✅
     2021年产出突增的原因：该年获批国自然面上项目，产出集中属于正常。

你：好的，生成报告吧。

LLM：[Step 7] 最终报告已生成。
     - 综合风险评级：中低风险
     - 核心发现：论文数量有夸大（31 vs 50），但质量尚可，无学术不端证据
     - 待核实：声称的50篇中是否有会议论文或报纸文章未被统计
     报告已保存为 Markdown 和 PDF。
```
