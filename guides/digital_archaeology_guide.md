# 数字足迹考古（Digital Archaeology）操作手册

本手册对应 `SKILL.md` 扩展模块 G。无需脚本，全部通过网页快照、多平台比对和手工记录完成。

---

## 一、调查目标

通过对比学者在不同平台、不同时间点的履历表述，识别以下三类问题：
1. **疑似学历/经历包装**：同一海外经历或头衔的表述不断升级（访问学者→博士后）。
2. **数字通胀**：不同平台对论文数量、H指数、获奖记录的声称存在明显夸大。
3. **信息选择性消失**：某些不利或无法验证的信息在最新版本中被悄然删除。

---

## 二、核心工具与入口

### 2.1 互联网档案馆（Wayback Machine）

- **网址**：`web.archive.org`
- **功能**：查看某一 URL 在历史上的所有存档快照
- **免费**：完全免费

**使用技巧**：
- 输入完整的学者个人主页 URL（如 `https://econ.xxx.edu.cn/szdw/zhangsan.html`）
- 若直接搜索无结果，尝试去掉末尾 `.html`，或搜索学院师资页面
- 点击年份环上的具体日期，进入当日快照
- **保存证据**：使用浏览器截图工具（推荐 Chrome 的"捕获整页"）保存为 PNG/PDF

### 2.2 多平台学者主页

| 平台 | 网址/入口 | 重点字段 | 可靠性 |
|:---|:---|:---|:---:|
| 机构官网 | 学者所在院系/研究所的个人页 | 职称、职务、教育背景、研究方向 | 高 |
| 中国知网学者库 | `kns.cnki.net` → 学者检索 | 发文量、被引量、H指数 | 中 |
| 万方学者检索 | `trend.wanfangdata.com.cn` | 发文量、被引量 | 中 |
| Google Scholar | `scholar.google.com` → 个人主页 | 总引用、H指数、i10指数 | 中（数据未审核） |
| ResearchGate | `researchgate.net` | 教育背景、工作单位履历 | 中（用户自填） |
| ORCID | `orcid.org` | 教育背景、工作经历、DOI关联 | 中高（受控较强） |
| 百度百科 | `baike.baidu.com` | 履历简介、获奖、兼职 | 低（开放编辑） |
| 维基百科 | `zh.wikipedia.org` | 同上 | 低 |

### 2.3 社交媒体与口碑平台

| 平台 | 搜索式 | 典型信号 | 可靠性 |
|:---|:---|:---|:---:|
| 知乎 | `张三 导师 / 张三 读研 / 张三 实验室` | 匿名或实名读研体验 | 低 |
| 小红书 | `张三 导师 / 避雷 张三` | 学生吐槽、课题组日常 | 低 |
| 微博 | `张三 导师` | 公开言论、合影、会议信息 | 低 |
| 导师评价网 | `daoshidianping.com`（不稳定） | 结构化评价（若可访问） | 中低 |

## 三、分步操作指南

### 步骤 1：多平台画像快照采集

#### 3.1.1 采集原则
- **同一日完成**：所有平台的截图尽量在同一天采集，避免时间差造成误判。
- **截图必须含时间戳**：推荐在截图中保留系统时间或浏览器状态栏。
- **保存原始 URL**：每个截图的文件名或 accompanying markdown 中必须记录来源 URL。

#### 3.1.2 标准化截图命名
```
{平台}_{学者姓名}_{YYYYMMDD}.png
```

**示例**：
- `institute_张三_20260415.png`
- `cnki_张三_20260415.png`
- `baike_张三_20260415.png`
- `scholar_张三_20260415.png`

#### 3.1.3 跨平台差异记录表
采集完成后，填写以下对比表：

```markdown
| 字段 | 机构官网 | 知网学者库 | 百度百科 | Google Scholar | 差异说明 |
|:---|:---|:---|:---|:---|:---|
| 出生年份 | 1977 | 未显示 | 1977 | 未显示 | 一致 |
| 博士学位 | 某校博士（2007） | 未显示 | 某校博士（2007） | 未显示 | 一致 |
| 海外经历 | 斯坦福大学访问学者（2010-2011） | — | 斯坦福大学博士后（2010-2011） | — | 百度百科升级表述 |
| 论文数量 | 70余篇 | 68篇 | 80余篇 | 92篇 | 差异显著 |
| H指数 | 未显示 | 12 | 未显示 | 18 | 差异显著 |
| 现任职务 | 研究员 | 研究员 | 研究员、特聘教授 | 研究员 | 百度百科多出头衔 |
```

**分析原则**：
- **机构官网与知网学者库的差异**：以知网核实数为准，机构官网若引用未经核实的数字，标记为"声称"而非"事实"。
- **百度百科与机构官网的差异**：百度百科为开放编辑，可信度最低。但若百度百科的表述升级后反向出现在机构官网，则构成疑似"包装回灌"信号。
- **Google Scholar 数字膨胀**：GS 常包含未发表论文、会议摘要、重复条目，其数字与 CNKI/WoS 的差异需明确标注来源。

### 步骤 2：Wayback Machine 时间轴追踪

#### 3.2.1 操作流程
1. 打开 `web.archive.org`
2. 输入学者机构主页完整 URL
3. 查看日历视图，选择有快照的日期
4. 建议每隔 **1-2 年**选取一个快照进行对比（至少覆盖 3 个时间点）

#### 3.2.2 记录模板：字段级时间轴
为每个关键字段建立独立的时间轴：

```markdown
### 字段：海外经历
| 快照日期 | 来源 URL | 原文表述 | 变化说明 |
|:---|:---|:---|:---|
| 2015-06-12 | web.archive.org/web/20150612/... | "2010-2011年赴美国斯坦福大学访问学者" | 基线表述 |
| 2018-09-03 | web.archive.org/web/20180903/... | "2010-2011年斯坦福大学博士后研究" | **升级**：访问学者→博士后 |
| 2022-11-15 | web.archive.org/web/20221115/... | "2010-2011年斯坦福大学高级访问学者" | **再次调整**：博士后消失，改为高级访问学者 |

### 字段：论文数量声称
| 快照日期 | 来源 URL | 声称数量 | 同期 CNKI 核实数 | 差异率 |
|:---|:---|:---:|:---:|:---:|
| 2015-06-12 | ... | "发表论文30余篇" | 28篇 | +7% |
| 2018-09-03 | ... | "发表论文50余篇" | 35篇 | +43% |
| 2022-11-15 | ... | "发表论文70余篇" | 39篇 | +79% |
| 2025-03-08 | ... | "发表论文80余篇" | 42篇 | +90% |
```

#### 3.2.3 升级模式识别
对比时间轴后，识别以下模式并标记：

| 模式 | 定义 | 示例 |
|:---|:---|:---|
| **渐进式升级** | 同一字段的表述随时间不断加码 | 访问学者→博士后→高级研究员 |
| **跳跃式膨胀** | 数字在某一时间点突然大幅增长，但数据库核实数未同步增长 | 论文数从35篇跳到70篇（核实仅+4篇） |
| **悄然消失** | 某不利信息从历史版本中删除，且无更正说明 | 某段无法验证的"联合培养博士"经历在2020年后消失 |
| **季节性更新** | 数字仅在评审季（如职称评审前3个月）临时膨胀，评审后回落 | 评审前声称"80余篇"，评审后改回"60余篇" |

### 步骤 3：简历版本比对

#### 3.3.1 来源获取
尽力收集学者在不同年份提交的官方材料：
- 学术会议手册中的学者简介
- 基金申请书中的"主要研究成果"
- 人才计划申报材料（如从公开公示中获取）
- 学术期刊特邀编辑的作者简介

#### 3.3.2 论文清单差异比对表
将不同版本的"发表论文"清单进行逐项对齐：

```markdown
### 比对版本
- 版本A：2018年某会议手册
- 版本B：2022年某基金申请书

| 论文标题 | 版本A中的信息 | 版本B中的信息 | 差异 | 严重性 |
|:---|:---|:---|:---|:---:|
| 《宏观经济分析》 | 2015，《经济研究》 | 2015，《经济研究》 | 无 | 低 |
| 《金融周期研究》 | 2016，《金融研究》 | 2017，《金融研究》 | 年份改晚1年 | 中 |
| 《债务危机预警》 | 未出现 | 2018，《管理世界》，第一作者 | 凭空新增 | 高（需核实是否存在） |
| 《区域发展差异》 | 2019，《中国工业经济》 | 2019，《经济学动态》 | 期刊名称不同 | 高（需核实发表期刊） |
```

#### 3.3.3 数字膨胀轨迹表
```markdown
| 版本年份 | 声称论文总数 | 声称CSSCI数 | 声称专著数 | 同期核实总数 | 膨胀率 |
|:---|:---:|:---:|:---:|:---:|:---:|
| 2018 | 35篇 | 20篇 | 2部 | 31篇 | +13% |
| 2020 | 50篇 | 30篇 | 3部 | 35篇 | +43% |
| 2022 | 70篇 | 45篇 | 4部 | 39篇 | +79% |
| 2024 | 90篇 | 60篇 | 5部 | 42篇 | +114% |
```

### 步骤 4：社交媒体考古

#### 3.4.1 检索策略
在各平台执行以下组合搜索：

```
"学者姓名" + "导师"
"学者姓名" + "实验室" / "课题组"
"学者姓名" + "避雷" / "劝退" / "坑"
"学者姓名" + "延毕" / "毕业要求"
```

#### 3.4.2 帖子评估表
对每一篇有价值的帖子，记录：

```markdown
### 帖子记录
- 平台：知乎 / 小红书 / 微博
- URL：https://...
- 发布日期：
- 获取日期：
- 是否实名/准实名：是 / 匿名
- 可验证信息项（如入学年份、专业、课题组人数）：
- 与公开记录的吻合度：
- 核心指控摘要：
- 可靠性评估：⭐☆☆☆☆ 至 ⭐⭐⭐⭐⭐
```

#### 3.4.3 缓存恢复技巧
若发现帖子已被删除，尝试以下方法恢复：

1. **Wayback Machine / 网页快照**
   - 在 `web.archive.org` 输入帖子完整 URL
2. **搜索引擎缓存**
   - 在百度/Google 搜索框输入 `cache:帖子URL`
   - 注意缓存通常保留时间较短（数天至数周）
3. **网页截图分享平台**
   - 搜索帖子标题+平台名，看是否有人转发了截图

## 四、综合判定与红旗生成

### 4.1 组装时间轴证据墙
将步骤1-4的发现汇总到一个可视化时间轴中（可用 Excel 或手绘）：

```
2010 ── 斯坦福大学访问学者（基线事实）
2015 ── 机构官网：访问学者
2018 ── 机构官网：博士后（首次升级）
2020 ── 百度百科：博士后
2022 ── 机构官网：高级访问学者（悄然回退）
       ── 同时论文声称数从50跳至70（核实39）
```

### 4.2 红旗信号清单
根据考古发现，对照以下清单生成红旗：

| 红旗信号 | 判定标准 |
|:---|:---|
| 疑似海外经历表述升级 | 同一经历在历年快照中出现职务/身份升级，且无学位证书佐证 |
| 头衔无中生有 | 某头衔首次出现在某年版本中，但无聘任公告 |
| 论文数字跨源差异≥30% | 简历/官网声称数与 CNKI/WoS 核实数差异超过30% |
| 时间线自我矛盾 | 不同版本对同一职务的起止时间存在2年以上冲突 |
| 信息悄然消失（疑似选择性删除） | 某段经历在最新版本中消失，且无更正说明 |
| 评审季数字膨胀 | 数字在职称评审前临时增加，评审后回落 |
| 社交媒体断裂 | 早期评价正面，近期出现大量一致负面指控且含可验证细节 |
| 被删帖缓存佐证 | 发现已被删除但缓存可读的实名/准实名爆料，且信息可部分验证 |

## 六、常见陷阱与排除方法

| 陷阱 | 排除方法 |
|:---|:---|
| **正常的履历更新被误判** | 学者 legitimately 晋升职称、发表新论文是正常现象。只有"无增量支撑的表述升级"才构成红旗。 |
| **百度百科被恶意编辑** | 百度百科开放编辑，存在竞争对手恶意修改的可能。需与机构官网快照交叉确认，若机构官网未跟进则不视为学者主动包装。 |
| **同名学者的帖子混淆** | 社交媒体上的匿名吐槽可能指向同名不同人。优先采信含可验证细节（学校、专业、年份）的帖子。 |
| **搜索引擎数字滞后** | Google Scholar 数字更新可能滞后于实际发表，导致"核实数"暂时偏低。应注明数据检索日期，避免误判。 |
