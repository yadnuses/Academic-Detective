# 魅影前后端链接方案（本地运行版）

> 版本: 1.0
> 日期: 2026-05-01
> 目标: 本地一键跑通，LLM预留OpenAI通用格式接口

---

## 一、总体架构

```
浏览器 (meiying.html)
        ↑↓ HTTP/SSE  localhost:8000
    FastAPI后端 (scripts/backend/)
        ↑↓ subprocess / 文件系统
    investigate.py + agent层 + 案件目录
        ↑↓ (预留)
    LLM接口层 (mock模式 ←→ OpenAI API)
```

**设计原则**:
- 后端只管API和流式推送，所有业务逻辑复用现有脚本
- LLM层可插拔：默认mock（基于真实案例数据），一键切换OpenAI
- 前端改动最小：保留现有UI，只把demo数据流换成SSE连接
- 本地运行，零外部依赖（除可选的OpenAI key）

## 二、端口与路由

| 服务 | 地址 | 说明 |
|:---|:---|:---|
| FastAPI后端 | `http://localhost:8000` | 提供所有API |
| 前端页面 | `http://localhost:8000/meiying` | 后端托管静态页面（开发便利） |
| 原前端 | `http://localhost:8080/meiying.html` | python3 -m http.server 8080 |

**API路由表**:

```
POST   /api/cases                    创建案件
GET    /api/cases                    列出所有案件
GET    /api/cases/{case_id}          获取案件详情
DELETE /api/cases/{case_id}          删除案件
POST   /api/cases/{case_id}/chat     发送消息 → SSE流返回
POST   /api/cases/{case_id}/upload   上传文件
GET    /api/cases/{case_id}/status   获取当前状态
POST   /api/cases/{case_id}/pause    暂停任务
POST   /api/cases/{case_id}/resume   恢复任务
GET    /meiying                      返回meiying.html
```

## 三、SSE事件协议

前端通过EventSource连接 `/api/cases/{case_id}/chat`，后端按顺序推送事件：

```json
// 1. 文本消息（魅影的自然语言回复）
{ "type": "text", "content": "收到。开始调查蔡正兰..." }

// 2. Agent状态更新（驱动像素小人切换）
{ "type": "agent_status", "agent": "zhu", "task": "官网信息提取", "state": "running" }
{ "type": "agent_status", "agent": "zhu", "task": "官网信息提取", "state": "completed" }

// 3. 关键发现（触发CRITICAL暂停）
{ "type": "critical", "finding": "学历-职称严重不匹配", "confidence": 0.95, "options": ["A. 深入调查", "B. 标记继续", "C. 暂停"] }

// 4. 流结束标记
{ "type": "done" }

// 5. 错误
{ "type": "error", "message": "脚本执行超时" }
```

## 四、LLM接口层设计

### 4.1 接口定义（OpenAI通用格式）

```python
class LLMClient:
    async def chat(
        self,
        messages: list[dict],           # [{"role": "system", "content": "..."}, {"role": "user", "content": "..."}]
        model: str = "gpt-4o",          # 可配置
        temperature: float = 0.3,       # 调查任务需要低temperature
        stream: bool = True,            # 默认流式
    ) -> AsyncIterator[str]:           # 逐字/逐段yield
```

### 4.2 双模式切换

| 模式 | 触发条件 | 行为 |
|:---|:---|:---|
| **mock模式**（默认） | 无OPENAI_API_KEY环境变量 | 基于意图分类和案例模板生成回复，模拟agent执行延迟 |
| **OpenAI模式** | 存在OPENAI_API_KEY | 直接调用OpenAI API，流式返回 |

### 4.3 mock模式的回复逻辑

mock不瞎编，而是基于真实案例数据生成结构化回复：

```
用户输入 → 意图解析（规则+关键词）
              ↓
    ┌─────────┼─────────┐
    ↓         ↓         ↓
  调查某人   查询状态   分析文件   其他
    ↓         ↓         ↓         ↓
  加载案例   返回STATE   调用工具   LLM通用回复
  模板数据   摘要      返回结果
    ↓
  分步SSE推送:
  - agent_status: zhu running
  - text: 基础画像表格
  - agent_status: zhu completed
  - agent_status: dududu running
  - text: 初步分析
  - agent_status: dududu completed
  - done
```

**mock数据源**: 直接读取 `调查名单/` 下的真实案件config.yaml和报告作为回复模板。

## 六、前端改动点

meiying.html需要修改的部分（保留所有现有样式和动画）：

### 6.1 新增：连接后端

```javascript
// 页面加载时连接SSE
let evtSource = null;
let currentCaseId = localStorage.getItem('current_case_id');

function connectSSE(caseId) {
  evtSource = new EventSource(`/api/cases/${caseId}/chat`);
  evtSource.onmessage = (e) => {
    const data = JSON.parse(e.data);
    if (data.type === 'text') addMessage(data.content, 'detective');
    if (data.type === 'agent_status') updatePixelAgent(data.agent, data.state);
    if (data.type === 'critical') showCriticalModal(data);
    if (data.type === 'done') { /* 本轮结束 */ }
  };
}
```

### 6.2 修改：发送消息

```javascript
// 原demo的initChat()改为真实发送
async function sendMessage(text) {
  addMessage(text, 'user');
  await fetch(`/api/cases/${currentCaseId}/chat`, {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({message: text})
  });
  // 回复通过SSE异步到达
}
```

### 6.3 修改：文件上传

```javascript
async function uploadFile(file) {
  const form = new FormData();
  form.append('file', file);
  const res = await fetch(`/api/cases/${currentCaseId}/upload`, {
    method: 'POST', body: form
  });
  const data = await res.json();
  // 后端自动触发处理链，通过SSE推送进度
}
```
