## Citation Fabrication Audit（虚假引文核查方法论）

核查论文参考文献的真实性，重点防范 AI 生成或二手误传导致的虚假引用。与引用计量分析（`citation_profiler.py`，查自引率/引用卡特尔）互补：本模块回答的问题是「**这条文献到底存不存在、写得对不对**」。

**核心原则**：每条判定必须附证据（数据库条目 URL、期刊目录页、检索日期与检索式）；凭印象判断 = 失职。查不到就如实写「未找到」，严禁编造证据。

**为什么必须 100% 逐条核验**：AI 生成的虚假文献有稳定指纹——题名仿真、期次选真实年份、作者选该领域真实学者。抽样核查恰恰是为漏掉它们设计的。

### Fabrication Typology（造假类型学 A–E）

| 类型 | 定义 | 典型形态 |
|:---|:---|:---|
| **A 凭空捏造** | 期刊该期查无此文 / 书不存在 | 真实学者 + 真实期刊 + 真实年份，但当期目录逐篇比对确证无此文；公开报道的学术造假事件中此类占比最高 |
| **B 真文献+假内容** | 文献真实存在，但卷次/页码/收录内容虚构 | 古籍实际只有 30 卷，被引作「卷 31」 |
| **C 时代错乱** | 文献收录其时代不可能见到的材料 | 清代汇编「收录」民国时期才出土的文献 |
| **D 伪造版本** | 真实论文 + 不存在的发表载体组合 | 预印本被著录为已发表于某期刊/会议；用 arXiv `journal_ref` 字段可证伪 |
| **E 引文与原文不符** | 正文转述/数字/引语与所引文献矛盾 | 经典实验的标志性数字被误传（沿袭二手文献的错误）；或正文转述的对象本身系编造（与 A 类互相印证） |

### Two-Step Judgment Order（判据顺序，不可跳步）

判 A 类「凭空捏造」是重结论，必须按固定顺序取证：

1. **题名全网精确检索**：引号包题名，跨 CNKI / 万方 / 维普 / 期刊官网 / Google Scholar / 百度学术检索。**若题名在其他年份或期次命中 → 该文献真实存在，降级为「著录错误（期次/年份有误）」，不得判伪造**——期次写错的真文献与空造文献性质完全不同。
2. **期次目录穷尽**：仅当全网检索在任何年份都无命中后，才调取所著录期刊当期**完整**目录逐篇比对（含分页、增刊、专栏），确认查无此文方可判 A 类。

仅有「全网检索 0 命中」而未穷尽目录时，结论降级为「**高度疑似**」，并在报告中写明证据强度。

### Source Priority（按文献类型选验证源）

| 文献类型 | 一级源 | 二级源 |
|:---|:---|:---|
| 中文期刊 | 期刊官网当期完整目录、CNKI 条目页 | 万方/维普、他引著录交叉 |
| 英文会议/期刊 | ACL Anthology（含官方 .bib）、ACM DL、Crossref API、出版社页 | DBLP、Google Scholar |
| 预印本 | arXiv API（查 `journal_ref` 是否为空，可证伪「已发表」声称） | OpenReview |
| 法律法规 | 国家法律法规数据库、gov.cn、court.gov.cn、EUR-Lex | 律所评析（须与原文互证） |
| 新闻报道 | 媒体官网原页（抓 `<title>` 复核标题） | 权威转载（须标注转载关系） |
| 古籍 | 识典古籍、CBETA、维基文库全文逐字比对 | 影印扫描件校读 |
| 图书 | 出版社官网、ISBN、馆藏 MARC | 豆瓣、百科 |

**一级源被反爬/付费墙时的降级规则**：第三方目录站 + 原刊 PDF 目录页 + 两篇以上他引著录交叉，三者一致可判「文献真实」，但报告必须写明验证层级（「二级源交叉验证，未见原库条目页」）。**「查无此文」的判定不享受降级**——A 类结论必须穷尽当期完整目录。

### Fabrication Fingerprints（高危信号，见到即重点核）

- 条目**无页码**，而同列表其他条目页码齐全
- 集中在「国内研究参照」「既有研究」类**排比句/综述段**
- 题名读起来「就该存在」（大词组合：视角/路径/再审视/治理）
- 真实学者 + 真实期刊 + 真实年份的组合（仿真度最高的形态）
- 转引二手文献的标志性数字与原文不符（沿袭二手误传）
- 脚注定义存在但正文无对应引用标记（写了没挂）

### Severity Classification（三档分类）

| 判定标签 | 归入档位 |
|:---|:---|
| 查无此文（A）/ 伪造版本（D）/ 时代错乱（C）/ 引文与原文矛盾（E）/ 虚构条文出处 | **【明确大问题】** 投稿/送审前必修 |
| 文献真实但著录有误（卷期、页码、年份、题名错字）/ 该注未注 / 转引未标 | **【明确小问题】** |
| 格式瑕疵 / 链接失效但文献真实 / 可改可不改的措辞 | **【无伤大雅】** |
| 未能核实（源不可达、证据不足） | **按【明确大问题】对待**，但标注证据强度受限（「高度疑似，目录源未能穷尽」），不得写成确证 |

### Extraction Caveats（提取盲区）

- python-docx 系工具（含 `citation_verifier.py` 的 docx 解析）**只读正文段落，不读脚注和尾注**——脚注/尾注引注是漏网重灾区。核查 docx 稿件时必须另行抽取 `word/footnotes.xml` 与 `word/endnotes.xml`：

```bash
unzip -p paper.docx word/footnotes.xml | grep -o '<w:t[^>]*>[^<]*</w:t>'
unzip -p paper.docx word/endnotes.xml  | grep -o '<w:t[^>]*>[^<]*</w:t>'
```

- 尾注制（endnote）稿件不查 `endnotes.xml` 会整片漏掉引注。
- 正文观点性引用（「某某（年份）指出」）不进参考文献表的，须从正文另行识别。

### Coverage Disclosure（范围收窄披露）

任务范围被收窄时（如委托方只要求核参考文献表、或时间/权限不足以抽查正文），明确声明放弃了哪些步骤，并在报告覆盖率节披露缺口（如「正文转述未抽查，E 类风险未排除」）。**收窄不等于可以装作做过**。

正文抽查建议 ≥10 处，优先抽查含具体数字、条文号、页码、直接引语的断言——E 类问题只在这一步暴露。

### Auditor Red Flags（核查者自律）

- 「这条我记得是真的」→ 必须找到证据 URL，否则写「未找到」
- 「CNKI 打不开就算了吧」→ 换期刊官网/万方/他引交叉，仍不行则如实标注验证层级受限
- 「抽样核几条代表一下」→ 无效，假文献就是为抽样设计的
- 「格式问题不用核内容」→ 题名拼凑、作者错字只在逐字段比对时暴露
- 「当期目录查无此文 = 伪造」→ 先做全网题名检索排除「期次写错的真文献」，再下 A 类结论
